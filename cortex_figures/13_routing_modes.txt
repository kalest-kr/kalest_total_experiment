그림 13 / 25 — 세 모드 비교 — 같은 P 에서 각 모드가 고르는 Q
범주: E V1 안내 라우팅 (v2)
이미지 파일: 13_routing_modes.png (2200 × 944 픽셀, PNG)
대상 프로그램: cortex_local_learning_v1.py + cortex_local_learning_v2_v1_guided_routing.py (v2.0.0)

[이 그림이 보여 주는 것]
같은 첫 입력 위치 P 에서 세 모드가 둘째 입력 위치를 각각 어떻게 고르는지 나란히 보여 준다.
개략도이며 축척은 맞추지 않았다. 회색 점 = V4 L4 격자 위치(예시), 파란 점 = P.

[legacy (왼쪽)]
v1 규칙을 그대로 재현한다. P 에서 θA 방향으로 D(국소 간격) 떨어진 점(×)에 가장 가까운 격자 위치를 고른다.
그 위치가 P 자신이면 같은 위치 P 를 그대로 쓴다. 곡선이 휘는 방향(현 방향)은 보지 않는다.
v1 프로그램이 만든 run 은 이 모드로 읽는다.

[geometry_only (가운데)]
수정된 기하 후보 집합(주황 점 1·2·3, 그림 14)에서 기하 순서 첫 후보(칸 1)를 늘 고른다. V1 안내 영향이 없다.

[v1_guided (오른쪽)]
geometry_only 와 정확히 같은 후보 집합을 쓴다. 파란 짧은 획은 이 이미지의 V1 방향 반응이다.
후보 경로 위의 V1 반응이 경로 방향을 가장 잘 지지하는 후보(★, 안내 점수 S 최대)를 고른다 (그림 15).
새 실행의 기본 모드다.

[아래 괄호 — 효과를 나눠 보는 방법]
- legacy → geometry_only: 기하 배선 수정 효과 (후보 위치 규칙이 바뀐 효과, 후보 없음으로 꺼지는 뉴런 포함)
- geometry_only → v1_guided: 안내 지도의 추가 효과 (같은 후보에서 고르는 규칙만 다름)
두 효과를 합쳐 하나로 보고하지 않는다.

[운영 규칙]
- 모드는 run 마다 하나로 고정된다. 프로그램은 사용자가 고른 한 모델만 학습한다.
- 비교하려면 같은 V1·V2 run 에서 다른 모드로 분기한 run 을 각각 학습한다 (그림 17).
- 고정 모델에서 안내만 바꿔 보는 진단(9-6)은 "즉각적 민감도 검사" 이며 학습한 모드 간 비교가 아니다.

[관련 코드]
ROUTING_MODES, _displaced (legacy), RoutingRuntime.select (geometry_only / v1_guided), 설정 routing.mode

[그림 공통 색 규칙]
- 파란 실선 화살표: 순방향 감각 신호 (이미지 → LGN → V1 → V2 → V4 → IT)
- 분홍 점선 화살표: 교정 신호 (δ, L1 배달, q 갱신)
- 주황 선·칸: v2 에서 추가된 V1 안내 라우팅
- 파란 칸: 표본마다 새로 계산하는 값, 분홍 칸: 저장·학습되는 값 (q, prototype)
- 초록 칸: 통과·정상 종료, 빨간 칸: 제외·오류·금지
- 회색 화살표: 프로그램 부품 사이의 호출·기록 순서
