[기본 검사 C01–C14 (메뉴 7-1, --diagnose)]
C01 같은 입력으로 반복 순방향·평가해도 같은 값
C02 교정 신호 m = 0 이면 q 불변, q 가 범위 [0, 4] 를 지킴
C03 L1 배달 주소가 실제 뉴런과 맞음
C04 교정 라우터 R: 열 합이 1, 부모 목록으로 직접 계산한 값과 일치, 총량 보존 (Σ m_L2 = α2 · Σ δ)
C05 입력 기여의 합이 u 와 같음 (v2 라우팅 행은 그 표본에서 실제로 고른 주소로, 후보 없음 행은 u = 0 으로 확인)
C06 동결 영역 불변
C07 prototype 은 train 으로만 만듦
C08 L6 가 q 를 바꾸지 않음
C09 q 변화가 다음 순방향에 반영됨
C10 반응 없는 뉴런 수 (시험 표본 모두에서 s = 0), q 가 하한·상한에 붙은 수, g 가 경계에 붙은 수
C11 교정 한 번 적용 전후 h 와 정답 prototype 사이 거리 변화 (h_before → h_after)
C12 prototype·출력 기하 (각도·노름)
C13 역할 반응 빠른 측정
C14 전역 기울기 호출 없음 (no_grad, 금지 패턴 탐색)

[역할 반응·교란 (메뉴 7-2, 7-3) — MEASURED]
V1 방향 선 자극(선호 방향 일치), V1 위상 변조, 균일 영상, V2 역할, V4 역할, 평행 이동,
교란 비교 l2_rows_within_position (위치 안에서 L2 행 섞기), l4_spatial (L4 공간 섞기)

[라우팅 구현 검사 R00–R12 (메뉴 9-4, --routing-check)]
R00 합성 직선으로 V1 채널 θ 가 선의 접선 방향인지 (법선이 아님)
R01 legacy 모드가 원본 v1 파일과 같은 출력·구조 해시·설정 해시를 내는지 (v1 파일이 같은 폴더에 있어야 실행)
R02 geometry_only 와 v1_guided 의 후보 표가 같고, V4 L4·L3·곡선이 아닌 L2 행·곡선 첫 입력 A 가 legacy 와 같은지
R03 Q ≠ P, 주소 범위, 0 패딩, 채널 = contour θB, 거리·방향 조건, 실제 선택도 유효 후보인지
R04 0/180° 방향 이음매, 극좌표 각도 이음매, 영상 경계, 후보 없음 u = 0, 안내 없음 → 기하 첫 후보, 영 입력
R05 선택 함수에 라벨 통로가 없고, 같은 이미지의 라벨만 바꿔도 선택이 같은지
R06 합성 안내 지도(목표 후보 경로 위에만 반응)에서 알려진 후보를 고르는지, float64 기준 구현과 점수 차
R07 전체 영상부터 처리한 원호 자극에서 선택 위치 측정 (MEASURED)
R08 배치 · 단일 표본 · 순서를 바꾼 배치에서 선택과 출력이 같은지 (두 모드 모두)
R09 저장·로드 뒤 후보 표 해시와 선택이 재현되는지
R10 검사 전후 q · prototype · RNG · 구조가 그대로인지
R11 CPU/GPU 선택·수치 비교, 근접 동점 따로 기록 (GPU 가 없으면 NOT_RUN)
R12 학습 텐서 requires_grad 없음, 금지된 미분 호출 없음

[곡선 역할 진단 자극 (메뉴 9-5) — MEASURED]
원호, 반대 곡률 원호, 중간이 끊긴 원호(같은 끝점 반응), 원호 끝의 두 점, 원호 꼭대기의 접선 직선,
꺾인 모서리, 교차선, 낮은 대비 원호, 위치를 옮긴 원호, 90° 회전한 원호, 잡음.
대상 뉴런 = 생성 원호 위에 P 가 있고 θA 가 접선(±15°)이며 곡률 부호가 진행 방향과 맞는 곡선 뉴런(기하 기준).
대상 뉴런의 평균 출력, 선택 Q 와 생성 경로의 거리, 선택 경로의 지점 통계를 모드별로 측정한다.

[안내 개입 진단 (메뉴 9-6, dev) — MEASURED, 즉각적 민감도 검사]
정상 V1 지도 / 공간 위치만 섞은 지도 / 방향 채널만 섞은 지도 (이상 v1_guided 선택 규칙) / geometry_only.
조건별 dev 정확도와 정상 안내 대비 선택이 바뀐 비율을 기록한다.

[관련 코드]
Diagnostics.c01 … c14, RoutingDiagnostics.r00 … r12, role_diagnostics, intervention_diagnostics

[그림 공통 색 규칙]
- 파란 실선 화살표: 순방향 감각 신호 (이미지 → LGN → V1 → V2 → V4 → IT)
- 분홍 점선 화살표: 교정 신호 (δ, L1 배달, q 갱신)
- 주황 선·칸: v2 에서 추가된 V1 안내 라우팅
- 파란 칸: 표본마다 새로 계산하는 값, 분홍 칸: 저장·학습되는 값 (q, prototype)
- 초록 칸: 통과·정상 종료, 빨간 칸: 제외·오류·금지
- 회색 화살표: 프로그램 부품 사이의 호출·기록 순서
