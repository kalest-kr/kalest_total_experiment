[이 그림이 보여 주는 것]
위: 오차 δ 가 L3 에서 L2 로 배달되는 방식과 q 갱신 식. 아래: 배치 하나를 처리하는 7 단계 주기.

[위 — L1 배달]
- j₁, j₂ = 활성 영역 L3 뉴런, i₁ … i₆ = L2 뉴런. 회색 선은 L2 → L3 순방향 연결(부모 목록 P(j))이다.
- δ = prototype정답 − h (h = 활성 영역 L3 전송 출력).
- L3 에 주는 신호: m_L3 = α3 · δ
- L2 에 주는 신호: m_L2[i] = α2 · Σ_(i 를 부모로 가진 j) δ_j / |P(j)|
  예: j₁ 은 부모가 4개라 1/4 씩, j₂ 는 3개라 1/3 씩. i₄ 는 두 L3 의 부모라 α2(δ₁/4 + δ₂/3) 를 받는다.
- 연결 가중치·전치 행렬·미분을 쓰지 않고 부모 목록의 개수만 쓴다. 역전파가 아니며 정확한 기울기라고 주장하지 않는다.

[위 오른쪽 — q 갱신 (분홍 칸)]
e = s / (s + e0), e0 = 1   (활동이 있는 뉴런일수록 1 에 가까움, s = 0 이면 갱신 없음)
Δq = η · 배치 평균(e · m),  η = 0.01,  α2 = α3 = 0.5
q ← clip(q + Δq, 0, 4)
- L2·L3 갱신량을 같은 스냅샷에서 모두 계산한 뒤 동시에 적용한다.
- L4 는 고정 중계라 학습하지 않는다. 앞 영역은 동결되어 q 가 바뀌지 않는다.

[아래 — 배치 하나의 7 단계]
1 상태 초기화: 이전 표본의 동적 값을 비운다
2 자유 순방향: h_before, s, CONF, g 를 계산
3 prototype 비교: 동결된(이번 에폭 동안 고정된) prototype 기준으로 δ
4 L1 배달: m_L3, m_L2 계산
5 q 갱신: 활성 영역 L2·L3 의 q 만
6 재순방향: 같은 입력으로 다시 계산해 h_after
7 효과 기록: 같은 prototype 기준으로 개선·악화·무변화 판정
(번호는 실제 실행 순서다)

[기록]
- training.csv: 거리 개선·악화 비율, q 효과(같은 P 기준 거리 변화), prototype 효과
- correction_samples/: 교정 표본, 에폭당 64개 · 단계당 512개까지

[V1 과 V4 의 차이]
V1 은 L3 하나에 부모가 4개(위상 2 × 극성 2)이고 L2 마다 부모 L3 가 하나다. V4 L3 처럼 이웃 평균을 하는 층에서는
i₄ 처럼 여러 L3 에서 몫을 받는 L2 가 생긴다.

[v2 영향]
라우팅은 L2 → L3 부모 목록을 바꾸지 않으므로 교정 매핑은 그대로다 (R02 에서 legacy 와 비교해 확인).

[관련 코드]
LocalErrorRouter (route), L1Packet, L1Relay (packet, deliver), LocalOutputLearner, StageTrainer._batch

[그림 공통 색 규칙]
- 파란 실선 화살표: 순방향 감각 신호 (이미지 → LGN → V1 → V2 → V4 → IT)
- 분홍 점선 화살표: 교정 신호 (δ, L1 배달, q 갱신)
- 주황 선·칸: v2 에서 추가된 V1 안내 라우팅
- 파란 칸: 표본마다 새로 계산하는 값, 분홍 칸: 저장·학습되는 값 (q, prototype)
- 초록 칸: 통과·정상 종료, 빨간 칸: 제외·오류·금지
- 회색 화살표: 프로그램 부품 사이의 호출·기록 순서
