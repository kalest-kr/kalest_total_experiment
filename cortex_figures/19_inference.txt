그림 19 / 25 — 추론 — 저장 모델로 이미지 한 장·폴더 예측
범주: F 운영
이미지 파일: 19_inference.png (2200 × 614 픽셀, PNG)
대상 프로그램: cortex_local_learning_v1.py + cortex_local_learning_v2_v1_guided_routing.py (v2.0.0)
==============================================================================
[이 그림이 보여 주는 것]
학습이 끝난(또는 진행 중인) 모델로 새 이미지를 분류하는 흐름.

[단계]
1 이미지 1장 또는 폴더 (하위 폴더까지 지원 확장자 파일을 찾음)
2 같은 전처리: 학습 때와 같은 크기 맞춤·DoG·로그-극좌표 (그림 04)
3 순방향: 고른 영역까지 (기본은 현재 활성 영역). v2 의 V1 안내 경로도 그대로 쓰고, 라벨은 요구하지 않는다
4 prototype 코사인: 그 영역의 prototype 과 비교해 예측
5 결과: inference/<시각>/ 폴더에 inference_results.csv · .json, 첫 이미지의 특징 그림

[결과 행에 들어가는 값]
이미지 경로, 상태, 예측 클래스, 클래스별 코사인, 출력 노름, 유효 출력 여부, 영역, 모델 버전, checkpoint,
원본 크기, 라우팅 모드, 라우팅 열(안내 없음 비율 · 기하 첫 후보와 다른 비율 · 선택 S 평균 · B = 0 비율 · 후보 없음 비율)

[규칙]
- q · prototype 을 갱신하지 않는다.
- 읽을 수 없는 파일은 멈추지 않고 load_failed 행으로 기록한다.
- 균일 영상처럼 출력이 영벡터면 unknown_zero_vector 로 표시한다 (자체 검사 ST10).
- 코사인 값은 확률이나 보정된 신뢰도가 아니다.

[실행 방법]
메뉴 6, 또는 --resume RUN --infer PATH

[관련 코드]
run_inference, list_images, save_feature_figure, cosine_classify

[그림 공통 색 규칙]
- 파란 실선 화살표: 순방향 감각 신호 (이미지 → LGN → V1 → V2 → V4 → IT)
- 분홍 점선 화살표: 교정 신호 (δ, L1 배달, q 갱신)
- 주황 선·칸: v2 에서 추가된 V1 안내 라우팅
- 파란 칸: 표본마다 새로 계산하는 값, 분홍 칸: 저장·학습되는 값 (q, prototype)
- 초록 칸: 통과·정상 종료, 빨간 칸: 제외·오류·금지
- 회색 화살표: 프로그램 부품 사이의 호출·기록 순서
