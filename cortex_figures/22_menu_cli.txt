[이 그림이 보여 주는 것]
위: 한국어 번호 메뉴 전체와 하위 메뉴. 아래: 명령줄 인자 표.
기존 번호 1–8 은 v1 과 같고, 라우팅 기능은 9번(주황 테두리) 아래에 모았다.

[메뉴]
1 데이터·저장 폴더 설정 / 환경 확인 (따옴표·공백·한글·역슬래시 경로 처리)
2 데이터 검사 및 학습·검증·시험 분할
3 새 V1 모델 생성 / 구조·연결 요약
4 활성 영역 학습 또는 중단 지점 재개 (끝난 단계는 추가 에폭으로 연장)
5 다음 영역 추가 및 단계 전환
6 저장 모델로 이미지 한 장·폴더 추론
7 진단
  7-1 기본 검사 14 항목   7-2 역할 반응 (통제 자극)   7-3 역할 교란 비교   7-4 뉴런 조회 (3×3)
  7-5 최종 test 평가      7-6 q·prototype 상태 요약   7-7 전처리 DC·정보 손실
8 모델·로그·시각화 저장
9 V1 안내 라우팅 (v2)
  9-1 상태·후보 통계        9-2 새 실행 모드 선택 (데이터 분할 전, 이미 run 이 있으면 새 run)
  9-3 다른 모드로 분기 (V1·V2 재사용, 새 run)   9-4 구현 검사 R00–R12
  9-5 곡선 역할 진단        9-6 안내 개입 진단 (dev)   9-7 라우팅 그림 (이미지 파일 또는 합성 원호)
  9-8 설계 변경 기록 (보기·추가)
0 종료 (checkpoint 저장 여부를 묻는다)

[명령줄 인자]
--self-test --output-dir D   극소 인공 이미지로 구현 자체 검사 22 항목 (사용자 데이터 미사용)
--data-root --output-dir     새 실행
--train-stage V1|V2|V4|IT    이 영역까지 순서대로 학습 (앞 단계 동결, 확인 질문)
--epochs N                   이번 실행에서 학습하는 단계의 예산을 완료 에폭 + N 으로 (끝난 단계는 목표 단계일 때만 연장)
--resume RUN                 run 폴더 이어 가기 (seed · 모드가 다르면 오류)
--routing-mode M             새 실행의 라우팅 모드 legacy · geometry_only · v1_guided
--branch-from RUN            RUN 의 V1·V2 를 재사용해 --routing-mode 로 V4 를 새로 만드는 새 run
--routing-check              라우팅 구현 검사
--routing-diag               곡선 역할 진단 + 안내 개입 진단
--diagnose / --role-test / --test-eval   기본 검사 14 항목 / 역할 반응 / 최종 test 평가
--infer PATH                 이미지 파일·폴더 추론
--device auto|cuda|cpu       장치
--backend auto|torch|numpy   계산 뒷단. NumPy 는 사용자가 명시할 때만 쓴다. CUDA 버전은 정하지 않는다
--seed / --config / --yes / --menu   seed · 설정 JSON 덮어쓰기 · 확인 질문 모두 예 · 인자가 있어도 메뉴로

[설치 메모]
필수 numpy, Pillow. GPU 는 PyTorch (pytorch.org 에서 자기 PC 드라이버에 맞는 명령으로 설치). 선택 matplotlib.
프로그램은 패키지를 자동 설치하지 않고 외부 서버에 접속하지 않는다.

[관련 코드]
MenuApp (m1 … m9, m9_mode, m9_branch), routing_status_lines, build_parser, run_cli, main

[그림 공통 색 규칙]
- 파란 실선 화살표: 순방향 감각 신호 (이미지 → LGN → V1 → V2 → V4 → IT)
- 분홍 점선 화살표: 교정 신호 (δ, L1 배달, q 갱신)
- 주황 선·칸: v2 에서 추가된 V1 안내 라우팅
- 파란 칸: 표본마다 새로 계산하는 값, 분홍 칸: 저장·학습되는 값 (q, prototype)
- 초록 칸: 통과·정상 종료, 빨간 칸: 제외·오류·금지
- 회색 화살표: 프로그램 부품 사이의 호출·기록 순서
