run_info.json           (v2 확장) 데이터·저장 경로, 프로그램 해시, 분기 원본
data_report.json        스캔 결과 (손상 · 미지원 · 빈 클래스 · 중복 그룹 · 충돌 · 원본 크기)
split_manifest.json     분할 목록, 데이터 지문, 분할 해시
class_to_index.json     클래스 번호
preprocessing.json      전처리 정보, DC 검사
architecture.json       층 · 연결 · 구조 해시 요약
training.csv            에폭 행 + 학습 전 행 (dev 정확도, 클래스별 정확도, 혼동행렬, 출력 노름, 거리 개선 비율,
                        q·prototype 효과, 시간, GPU 최대 메모리, 캐시 크기, 라우팅 통계 열)
prototype_metrics.csv   prototype 최소 쌍각, collapse 경고
evaluations.jsonl       모든 dev · test 평가와 누적 횟수
stage_transitions.jsonl 단계 전환, 사용자 선택, 경고, 분기
design_changes.jsonl    (v2) 설계 변경 기록 (test 를 본 뒤의 변경인지 표시)
oom_events.jsonl        (v2) 메모리 부족 재시도 기록
diagnostics.json        진단 실행 색인
execution.log · errors.log  실행 · 오류 로그
result_summary.md       저장 기록에서 만든 결과 요약 (라우팅 절 포함)
