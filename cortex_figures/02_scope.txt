[이 그림이 보여 주는 것]
프로그램의 설계 범위를 네 칸으로 정리했다: 구현한 것, 일부러 하지 않은 것, v2 의 연구 질문,
진단으로만 확인할 수 있는 미검증 가설. 아래 문장은 v2 결과를 해석하는 기준이다.

[기본 입장]
생물학에서 착안한 공학적 근사다. 인간 시각 피질을 재현한다고 주장하지 않고, 학습 성공을 보장하지 않는다.
대신 각 가정이 실제로 작동하는지 확인할 수단(진단 검사와 기록)을 함께 넣었다.

[구현한 것]
- 망막/LGN 의 중심-주변 대립 반응과 ON/OFF 경로, 시선 중심에서 멀수록 거칠어지는 로그-극좌표 표본
- V1 방향·위상 단순 세포 근사와 위상 풀링, V2 윤곽·끝점·교차, V4 곡선 조각, IT 넓은 결합
- 영역마다 L4 → L2 → L3 경로, L6 국소 이득 조절, L1 위에서 오는 교정 신호 수신
- 결정론적 rate 모델, 3×3 논리 표기, 연속 텐서 + 정수 CSR 연결
- q 만 학습하는 국소 교정 휴리스틱과 prototype EMA, 영역별 순차 학습·동결
- v2: V4 곡선 뉴런 둘째 입력의 이미지별 위치 선택 (legacy · geometry_only · v1_guided)

[하지 않은 것]
- 활동전위·이온 전하·전도도·생물학적 ms 재현, 확률적 스파이크, NMDA, GABA-B
- 역전파·autograd·optimizer·surrogate gradient·손실 유한차분
- 임계값 학습, prototype 각도 강제·벌리기, L5 사용, 방향 선택적 억제 풀
- 헤브 필터 자율 형성, 적응·피로, 예측 부호화 전체 회로, 전체 미세조정
- v2: 영구 재배선, softmax 혼합·후보 합산, V1 활동을 V4 출력에 더하기
- 세 모드 동시 학습·시드 반복·격자 탐색 자동 실행 (사용자가 고른 한 모델만 학습)

[v2 연구 질문]
앞단 V1 에 보존된 위치·방향 특징을 별도 경로로 참조하면, V4 곡선 뉴런이 입력받을 이웃을 더 적절하게
고르고 자기 역할을 더 잘 수행하는가? U-Net 에서 빌린 것은 "앞단의 세밀한 공간 정보를 뒤쪽 처리에
다시 제공한다" 는 스킵 연결 착상뿐이다. U-Net 자체가 구조적 재배선을 한다는 뜻이 아니다.

[미검증 가설 — 진단으로만 확인]
- 국소 q 교정이 prototype 오차를 줄이고 분류를 개선한다
- L6 상대 활동 조절이 약한 특징 보존·분류에 도움이 된다
- 고정 역할 연산이 실제 이미지에서 그 역할을 한다
- 순차 동결이 상위 영역에 충분한 정보를 남긴다 · prototype EMA 가 collapse 하지 않는다
- V1 안내 선택이 곡선 역할 반응이나 분류를 개선한다

[해석 기준 문장]
V1 안내에 따른 입력별 연결 선택이며, 영구 재배선이나 인간 피질의 재현을 입증한 것은 아니다.

[관련 위치]
프로그램의 ASSUMPTIONS · FORMULAS 상수 → run 폴더의 assumptions.md, 파일 상단 docstring

[그림 공통 색 규칙]
- 파란 실선 화살표: 순방향 감각 신호 (이미지 → LGN → V1 → V2 → V4 → IT)
- 분홍 점선 화살표: 교정 신호 (δ, L1 배달, q 갱신)
- 주황 선·칸: v2 에서 추가된 V1 안내 라우팅
- 파란 칸: 표본마다 새로 계산하는 값, 분홍 칸: 저장·학습되는 값 (q, prototype)
- 초록 칸: 통과·정상 종료, 빨간 칸: 제외·오류·금지
- 회색 화살표: 프로그램 부품 사이의 호출·기록 순서
