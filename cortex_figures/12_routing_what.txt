[이 그림이 보여 주는 것]
v2 가 바꾼 연결 하나. V4 L2 곡선 뉴런의 둘째 입력 B 를 어디서 받을지 이미지마다 고르는 부분이다.

[곡선 뉴런의 원래 계산]
곡선 뉴런은 두 입력의 min 으로 반응한다.
A = V4 L4 전송 출력[P, θA]  (첫 입력: 위치 P 의 θA 방향 윤곽)
B = V4 L4 전송 출력[Q, θB]  (둘째 입력: 위치 Q 의 θB 방향 윤곽, θB = θA + 곡률 부호·κ)
u = min(A, B)

[그림 읽는 법]
- 왼쪽 위 V1 L3 전송 출력: 같은 순방향에서 이미 계산한 휘도 12 방향 지도 F1. 주황 점선으로 선택기에 "안내로만"
  들어간다. V4 출력에 더하거나 이어 붙이지 않고, 안내를 위해 V1 을 다시 실행하지도 않는다.
- 왼쪽 아래 V4 L4 전송 출력:
  · [Q₁ … Q_K, θB] 후보 (주황): 고정 후보 K 개(최대 8)의 θB 값을 모아(gather) 선택기로 보낸다.
  · [P, θA] → A: 첫 입력은 그대로 min 칸으로 간다 (파란 선, 선택기를 거치지 않음).
- 선택기: 후보마다 안내 점수 S(P, Q_k) 를 계산하고 가장 큰 후보 하나를 고른다 (hard top-1, 동점은 기하 순서).
  고른 후보 Q* 의 θB 값이 B 다 (그림 15).
- u = min(A, B): 후보가 하나도 없으면 u = 0 (missing_candidate). 안내 점수 S 를 u 에 곱하지 않는다.
- 이후 계산 그대로: 임계값 · q · L6 · L3 → IT 순서는 v1 과 같다.

[바뀌지 않는 것]
- 곡선 뉴런의 첫 입력 A, 둘째 입력의 채널(contour θB)
- 같은 V4 L2 의 직선·접합·선끝 채널, V1·V2·IT 전부
- L1 교정 규칙과 L2 → L3 부모 목록

[동적 라우팅과 영구 재배선의 구분]
후보 목록(정적 연결 표)은 V4 를 만들 때 한 번 정해지고 학습 중 바뀌지 않는다. 이미지마다 그중 하나를
고를 뿐이므로 영구 재배선이 아니다. 선택 함수에는 라벨·prototype·오차가 들어가지 않고, 이번 이미지의 선택이
다음 이미지의 선택에 영향을 주지 않는다.

[관련 코드]
build_v4 (curve_info, routed 행), build_routing_table, RoutingTable, RoutingRuntime.select,
CortexModel.forward (routing_mode, guide_transform, routing_record)

[그림 공통 색 규칙]
- 파란 실선 화살표: 순방향 감각 신호 (이미지 → LGN → V1 → V2 → V4 → IT)
- 분홍 점선 화살표: 교정 신호 (δ, L1 배달, q 갱신)
- 주황 선·칸: v2 에서 추가된 V1 안내 라우팅
- 파란 칸: 표본마다 새로 계산하는 값, 분홍 칸: 저장·학습되는 값 (q, prototype)
- 초록 칸: 통과·정상 종료, 빨간 칸: 제외·오류·금지
- 회색 화살표: 프로그램 부품 사이의 호출·기록 순서
