      - neuron_id = 모델 전체에서의 순번 (층마다 연속된 범위를 차지).
      - 입력군 A / B = 한 뉴런이 받는 두 묶음의 입력 연결. 보통 뉴런은 A 만 쓰고 u = ΣA. "min2" 뉴런은 u = min(ΣA, ΣB).
      - transmitted (실제 전송 출력) = 다음 층으로 실제로 넘어가는 값. CONF = L6 조절 전 기본 출력.

0-1. 이 프로그램이 하는 일 (한 문단)
  이미지 폴더 (하위 폴더 이름 = 클래스) 를 읽어 train/dev/test 로 나누고, 각 이미지를 망막/LGN 근사 전처리로
  로그-극좌표 표본 벡터 (4,096 개 값) 로 바꾼 뒤, V1 → V2 → V4 → IT 네 영역을 차례로 통과시킨다.
  각 영역은 L4 (입력 수신·중계) → L2 (역할 연산) → L3 (정리·풀링) 세 층이다. 마지막으로 학습 중인 영역의 L3 출력 h 를
  클래스별 prototype (train 출력의 클래스 평균) 과 코사인 유사도로 비교해 분류한다. 학습은 역전파가 아니라,
  prototype 과의 차이 δ 를 L3 → L2 부모 목록을 따라 나눠 주고 각 뉴런의 출력 배율 q 하나만 국소 규칙으로 고치는 방식이다.
  영역은 V1 부터 하나씩 추가하며, 새 영역을 추가하면 앞 영역은 동결 (q·prototype 고정) 한다.
  v3 에서 새로 바뀐 것은 V4 L2 의 "곡선" 뉴런이 받는 두 번째 입력군 B 계산 하나뿐이다 (강도 구간 게이트).

4-1. Backend [L815]
  모든 수치 연산을 한 곳에 모은 클래스. kind = "torch" (기본, GPU 또는 CPU 텐서) 또는 "numpy" (사용자가 명시할 때만).
  생성자 [L824]:
    · torch 이면 torch.set_grad_enabled(False) → 자동 미분 추적을 전역으로 끈다 (역전파 계산 그래프가 생기지 않는다).
    · CUDA 를 골랐는데 쓸 수 없으면 오류. TF32 를 끈다 (행렬곱 정밀도 고정). use_deterministic_algorithms(True).
  생성·변환: f32 / i64 / bool_ (numpy 배열 → 장치 텐서), to_np (장치 → numpy), zeros, zeros_i64.
  축 연산: max_last, argmax_last, sum_last, mean0, sum0, norm_last, exp, sqrt, relu (= max(0,x)), clip, minimum, where.
  주소 연산 (연결 계산의 바탕):
    · take_cols(x, idx) = x[:, idx] : 고정 정수 주소로 열을 모은다 (gather). 주소 배열이 2 차원이면 결과도 (B, r, K).
    · take_last(table, k)          : 표본마다 다른 slot k 를 골라 table[j, k[b,j]] (v2 라우팅의 선택 주소).
    · gather_cols(x, idx)          : 표본마다 다른 주소로 값을 모은다.
    · pad_zero_col(x)              : 마지막에 0 열을 하나 붙인다. 빈 연결 칸은 이 0 열 주소 (n_src) 를 가리키게 해서
                                     "−1 주소" 없이 안전하게 0 을 더한다 (모든 연결 표의 공통 규칙).
  ★ ell(xe, idx, w) [L907] — 정적 연결의 실제 계산
      xe: (B, n_src+1) 원천 층 출력 (마지막 열 0). idx, w: (r, K) 행마다 K 개의 원천 주소와 가중치.
      결과 (B, r) = Σ_k xe[:, idx[r,k]] · w[r,k]. 즉 "수신 뉴런 r 의 입력 합 u_r = Σ (가중치 × 송신 뉴런의 실제 전송 출력)".
      한 번에 모으는 원소 수가 max_gather (2^25) 를 넘으면 행을 나눠 계산해 이어 붙인다 (메모리 조각, 결과는 같다).
      덧셈 순서가 고정된 gather·곱·마지막 축 합만 쓰고 atomic 누적 (index_add) 을 쓰지 않아 같은 입력은 같은 결과를 낸다.
  기타: assign_ (q 덮어쓰기), add_row_, sync (CUDA 동기화), requires_grad_any / grad_enabled (역전파 미사용 검사용), describe.
4-2. is_oom_error [L1005]: GPU 메모리 부족 예외인지 판별 (재시도 경로에서 사용).

 제 7 부. 망막/LGN 전처리 — V1 L4 의 입력을 만드는 단계 [L1500–L1766]
======================================================================================================

7-1. logpolar_positions [L1503]
  로그-극좌표 표본 위치. 반경 bin k (0..n_r−1) 에서 u_k = (k+0.5)/n_r, r = r0·(exp(u·L) − 1), L = log(1 + Rmax/r0).
  각도 bin m 에서 φ = 2π(m + 0.5)/n_phi. 화소 좌표 x = cx + r·cosφ, y = cy − r·sinφ (화면 y 는 아래로 증가하므로 부호를 바꾼다).
  위치 번호 pos = k·n_phi + m (반경 우선). 국소 표본 간격 spacing_r = (r + r0)·L/n_r, spacing_phi = 2πr/n_phi 도 함께 돌려준다.
  기본 LGN: 32 고리 × 64 각도. 고리 반경은 0.11, 0.35, 0.62, … , 52.4, 58.63 화소 (가운데는 촘촘, 바깥은 성김).
  같은 함수가 V1 격자 (16×32) 위치에도 쓰인다 (같은 r0·Rmax).

7-2. 커널 함수 [L1520–L1546]: gauss1d (합 1 로 정규화한 1 차원 Gaussian), _conv1d_reflect (reflect 경계 1 차원 합성곱),
     blur2d (가로·세로 분리 합성곱).

7-3. RetinaLGNPreprocessor [L1549]
  생성자 [L1559]: S=128, 중심 cx = cy = 63.5, 색 채널 lum → 맵 ["lum_on", "lum_off"] (n_maps = 2).
    LGN 위치 2,048, 출력 길이 n_out = 2,048 × 2 = 4,096.
    각 위치가 쓸 흐림 단계: 요구 σ = 0.5 × max(spacing_r, spacing_phi) 에 가장 가까운 단계 (0/1/2/4/8 화소).
      기본 설정에서 위치 수: 0 화소 896, 1 화소 640, 2 화소 448, 4 화소 64, 8 화소 0.
    쌍선형 보간 표 (_bil): 각 표본 점을 둘러싼 네 화소와 가중치.
    가운데 고리가 매우 작아 0.5 화소 안에 겹치는 표본 쌍을 센다 (기본 11,872 쌍; 기록만 하고 지우지 않는다).
  처리 단계:
    resize_pad [L1601]: 긴 변을 128 에 맞춰 Lanczos 확대/축소, 짧은 변은 가운데 정렬 후 가장자리 복제 패딩. 값 범위 [0,1].
    opponent [L1614]: lum = R+G, rg = R−G, by = B − (R+G)/2 (디지털 RGB 근사).
    dog [L1618]: DoG = gain × (G_σc * m − G_σs * m). 각 커널 합이 1 이라 균일 영상의 DoG 는 0.
    lgn_maps [L1621]: 색마다 ON = max(0, DoG), OFF = max(0, −DoG).
    sample [L1630]: 흐림 단계별로 맵을 흐린 뒤, 그 단계를 쓰는 위치에서 쌍선형 보간으로 값을 뽑는다.
      출력 벡터 순서: index = pos × n_maps + map  → [pos0 ON, pos0 OFF, pos1 ON, pos1 OFF, …].
      ★ 이 순서가 그대로 V1 L4 의 local 순서다 (V1 L4 뉴런 i 는 LGN 값 i 하나만 받는다).
    from_array / from_path: 배열·파일 → LGN 벡터.
  진단: info (설정·고리 반경·흐림 단계 정보), dc_check (균일 색 영상에서 DoG·LGN 출력이 1e-6 이하인지),
        _nearest / info_loss (표본으로 화소를 복원해 이심률 구간별 정보 손실을 잰다).

7-4. BatchLoader [L1734]
  분할 항목 목록 → LGN 벡터 배치 (B, 4,096) 와 라벨 (B,). 파일 읽기·전처리 시간을 따로 잰다.
  RAM 캐시 (상한 1024 MB) 와 분할별 접근 횟수 (train/dev/test/external) 를 센다 (dev/test 사용 기록).

  [L1768–L1873] StimulusFactory: 진단용 통제 자극 (선, 격자 무늬, 교차, 모서리, 원호, 원·사각형·삼각형·별 도형, 균일 영상) 을
  3 배 초표본으로 그린 뒤 평균 축소해 매끄러운 경계로 만든다. 좌표는 화면 중심 기준, y 위쪽, 반시계 각도.
  학습 데이터가 아니라 역할 진단과 자체 검사에만 쓴다.

 제 8 부. 연결 구조의 기본 단위 [L1875–L2127]   ★ 뉴런·층 연결의 핵심
======================================================================================================

8-1. LayerSpec [L1879] — "한 영역의 한 층" 의 고정 구조 (CPU numpy 배열)
  이 객체 하나가 한 층의 모든 뉴런과 그 뉴런들이 받는 모든 입력 연결을 담는다. 학습 중에 바뀌지 않는다.
  필드:
    area, name            : 예) "V2", "L2".  key = "V2/L2".
    src_key, n_src        : 입력을 받는 원천 층 이름과 그 층의 뉴런 수 (예: V2/L2 의 원천은 V2/L4, 1,536 개).
                            ※ 모든 층은 바로 앞 층 하나에서만 입력을 받는다 (층을 건너뛰는 연결·되먹임 흥분 연결 없음).
    n_pos, n_ch           : 위치 수와 위치당 채널 수. 뉴런 수 n = n_pos × n_ch. local = 위치 × n_ch + 채널.
    channel_names / channel_roles / channel_meta : 채널 이름 (예: "contour_o30"), 역할 태그, 채널별 정보 (방향, 계열 family 등).
    op_min (n,)           : True 면 그 뉴런은 min2 연산 (u = min(ΣA, ΣB)), False 면 선형 (u = ΣA).
    a_ptr, a_src, a_w     : 입력군 A 의 CSR 표. 뉴런 j 의 A 입력은 a_src[a_ptr[j] : a_ptr[j+1]] (원천 층 local 주소),
                            가중치는 같은 범위의 a_w.
    b_ptr, b_src, b_w     : 입력군 B 의 CSR 표 (min2 뉴런만 사용). 선형 뉴런의 B 는 비어 있어야 한다.
    x, y, rf (n,)         : 각 뉴런의 수용장 중심 (처리 영상 화소) 과 수용장 반경.
    ring, ang (n,)        : 피질 격자 위치 (반경 bin, 각도 bin).
    pos_x, pos_y, pos_rf  : 위치별 중심과 수용장 반경 (n_pos,).
    grid_shape            : (n_r, n_phi). IT L2/L3 는 None (위치 하나).
    pos_nb, pos_nb_count  : L6 이웃 계산용 위치 이웃 표 (Chebyshev 반경 내 위치, 빈칸은 n_pos).
    learnable             : q 학습 대상인지 (L2·L3 True, L4 False).
    l6_capable            : L2·L3 만 True.
    description / build_stats : 사람이 읽는 설명과 생성 통계 (중복 연결 병합 수, 끝 위치에서 없는 이웃 수 등).
    start, end            : 모델 전체의 neuron_id 범위 (NeuronStore 에 넣을 때 정해진다).
    routed (n,) bool      : V4 L2 곡선 뉴런처럼 B 를 이미지마다 따로 계산하는 행. 이 행의 정적 B 는 비어 있다.
    missing (n,) bool     : 후보가 정말 없는 곡선 뉴런 (u = 0 으로 둔다).
    routing / band        : v2 모드의 RoutingTable 또는 v3 모드의 BandTable (V4/L2 에만).
  메서드: key, n, z (= 영역번호×10 + 층번호: V1 L4 = 14, V2 L2 = 22, IT L3 = 43), fan_in (A+B 입력 수),
          row(j) (뉴런 j 의 A·B 입력 목록), hash (구조 해시 — legacy 는 v1 과 같은 값, 라우팅/구간 모드는 표 해시까지 포함).

8-2. CSRBuilder [L1957] — 연결 목록을 만드는 도구
  행 (수신 뉴런) 마다 {송신 주소: 가중치} 사전을 A·B 두 개 둔다. add(row, src, w, group) 는
    · 송신 주소가 원천 층 범위 밖이면 StructureError,
    · 같은 (수신, 입력군, 송신) 이 다시 오면 가중치를 더해 하나로 합친다 (merge_sum 정책, 합친 횟수 merged 기록).
  finalize() 는 행마다 송신 주소를 오름차순으로 정렬해 CSR (ptr, src, w) 배열 두 벌 (A, B) 을 만든다.
  기본 설정에서는 모든 층에서 합쳐진 중복이 0 이다.
  identity_csr(n) [L1993]: 일대일 연결 (뉴런 i ← 원천 i, 가중치 1, B 없음).

8-3. grid_neighbors [L1998]
  피질 격자에서 Chebyshev 거리 ≤ radius 인 위치 목록 (자기 위치 포함). 각도 방향은 한 바퀴 돌아 이어지고 (wrap),
  반경 방향은 가장 안쪽·바깥 고리에서 잘린다. 그래서 반경 1 이면 안쪽·바깥 고리 위치는 이웃 6 개, 나머지는 9 개.
  쓰는 곳: 모든 층의 L6 이웃 (pos_nb), V4 L3 의 풀링 이웃, v3 정규화 이웃.
  single_position_neighbors [L2018]: IT 처럼 위치가 하나뿐인 층용 ([[0]], 개수 1).

8-4. validate_layer [L2022] — 모든 층을 만들 때마다 자동 검사 (어기면 StructureError 로 멈춤)
  · 배열 길이가 n 과 같은지, 채널 이름 수 = n_ch.
  · A·B CSR 형식 (ptr 단조 증가, 길이 일치), 주소가 [0, n_src) 안, 가중치 유한, 남은 중복 연결 0.
  · 선형 뉴런에 B 가 있으면 오류. routed 행은 반드시 min2 이고 정적 B 가 비어 있어야 한다.
  · min2 뉴런은 A 와 B 가 모두 있어야 한다 (routed 행은 B 를 후보 표로 대신하므로 예외).
  · L3 층에 입력 없는 뉴런 (부모 없는 L3) 이 있으면 오류 → 교정 배분 R 이 항상 정의되게 한다.
  · 팬인 최소·평균·최대, 입력 없는 뉴런 수, min2 수를 build_stats 에 남긴다.

8-5. 보조 함수 [L2060–L2127]
  · _channel_meta: 채널별 정보 열의 길이 검사.
  · _block_children(nr_c, nphi_c, nr_p, nphi_p) [L2067]: 아래 격자 (자식) 를 위 격자 (부모) 로 묶는 블록 목록.

  · _pool_positions [L2076]: 부모 위치 = 자식 중심들의 평균, 부모 수용장 반경 = max(자식까지 거리 + 자식 수용장 반경).

  · _displaced(px, py, P, θ, D, sign) [L2090]: 위치 P 에서 선 방향 θ 로 (sign = +1 앞, −1 뒤) D 화소 떨어진 점에

9-2. V1 L2 — 위치별 방향·위상 Gabor 단순 세포 (24,576 뉴런 = 512 위치 × 48 채널)
  위치: logpolar_positions(16, 32, …) → 512 위치 (LGN 과 같은 r0·Rmax, 더 성긴 격자).
  채널 48 = 색 1 (lum) × 방향 12 (0~165°) × 위상 2 (0, −π/2) × 극성 2 (+, −). 채널 순서: (색, 방향, 위상, 극성).
     이름 예: "lum_o30_p1_-" = 30° 방향, 두 번째 위상, 음 극성.
  필터 크기 (위치마다 다름):
     sp1 = sqrt(spacing_r × spacing_phi) (V1 격자의 국소 간격), σ = max(1.0 × sp1, 1.5 화소),
     파장 λ = 2σ, 수용장 반경 rad = 2σ.  기본 설정: σ 1.5~11.64 화소, λ 3.0~23.27 화소 (가운데 224 위치는 σ 하한 1.5).
  ★ 어떤 LGN 뉴런과 연결되는가 [L2162–L2169]:
     V1 위치 p 에서 원영상 거리 ≤ rad[p] 인 모든 LGN 표본 위치 (sel). 하나도 없으면 가장 가까운 표본 하나 (기본 설정에서 0 회).
     그 각 표본 위치의 ON 맵 L4 뉴런과 OFF 맵 L4 뉴런 둘 다에 연결한다 → 팬인 = 2 × (반경 안 표본 수).
     기본 설정: 팬인 84~1,084 (평균 359.75), V1 L2 전체 연결 8,841,216 개 (모델 전체 연결의 대부분).
  ★ 가중치를 정하는 식 [L2178–L2203]:
     표본의 상대 좌표 (vx, vy) = (표본 x − 위치 x, −(표본 y − 위치 y))   (y 를 위쪽으로 뒤집음)
     along = vx·cosθ + vy·sinθ (선 방향 축),  perp = −vx·sinθ + vy·cosθ (선에 수직인 축)
     envelope env = (표본 면적) × exp(−(along² + perp²)/(2σ²))       (바깥쪽 표본은 면적이 커서 더 큰 몫)
     carrier = cos(2π·perp/λ + φ)                                    (perp 방향으로만 변함 → θ 방향 선에 반응)
     DC 제거: g = env × (carrier − env 가중 평균 carrier)              (균일 밝기에 반응 0)
     정규화: g ← g / Σ|g|                                           (필터 크기와 무관하게 Σ|g| = 1)
     극성 +: ON 표본 가중치 +g, OFF 표본 가중치 −g.   극성 −: 반대 (ON −g, OFF +g).
     → u = Σ g·(ON − OFF) = Σ g·DoG 의 부호 있는 필터 응답. 출력 s = max(0, u − 0) 이라 + 극성 뉴런은 양의 응답만,
        − 극성 뉴런은 음의 응답만 내보낸다 (부호를 두 뉴런으로 나눔).
     퇴화 필터 (Σ|g| ≈ 0) 수를 센다 (기본 0).
  op_min 없음 (전부 선형), learnable True, L6 적용 (같은 층 이웃 위치 6~9 개 × 48 채널 − 자기 자신 = 287~431 개와 비교).

9-3. V1 L3 — 위상×극성 풀링 (6,144 뉴런 = 512 위치 × 12 채널)
  채널 = 색 × 방향 (12). 이름 예: "lum_o30".
  ★ 연결: V1 L3 (p, 색 c, 방향 o) ← 같은 위치·색·방향의 V1 L2 4 개 (위상 2 × 극성 2), 각 가중치 1/4.
     주소 = p×48 + ((c×12 + o)×2)×2 + {0,1,2,3}. 각 V1 L2 뉴런은 정확히 한 L3 에 들어간다 (팬아웃 1).
  u = 네 L2 실제 전송 출력의 평균. 완전한 위상 불변성을 주장하지 않는다.
  learnable True, L6 적용 (이웃 71~107).

     B 는 순방향 때마다 따로 계산한다: v2 모드는 RoutingTable 에서 후보 하나를 골라 그 값, v3 모드는 BandTable 후보들의 가중평균.
  straight (θ):
     A = contour(P, θ), B = contour(앞 이웃, θ) (앞이 없으면 뒤 이웃, 그것도 없으면 P). min2 → 같은 방향이 이어질 때 반응.
     예) straight_o0 at P=0 ← A: V4 L4 local 0, B: local 162 (위치 3). 기본 설정에서 뒤 이웃을 쓴 경우 72, 같은 위치 0.
  junction (교차 채널 k): A = V4 L4 (P, k) 가중치 1 (V2 교차 반응을 그대로 중계).
  lineend (θ): A = 0.5·endstop_fwd(P, θ) + 0.5·endstop_bwd(P, θ).
  기본 설정 (band_gated): A 연결 2,496 (= 위치당 곡선 24 + 직선 12 + 접합 18 + 선끝 24), B 연결 384 (직선만), min2 1,152 (곡선 768 + 직선 384).
  legacy 였다면 곡선도 정적 B 를 가져 B 연결이 384 + 768 = 1,152 가 된다.
  [L2442–L2459] 모드별 표 생성:
     v2 모드 → build_routing_table (제 13 부) → missing 행 (후보 없는 곡선) 표시.
     v3 모드 → build_band_table(cfg, pre, L4, prf + D, …) (제 14 부). 수용장 반경으로 prf + D (V4 L2 의 저장된 수용장) 를 넘긴다.
     기본 설정: 곡선 뉴런 768, 후보 없음 0, 후보 평균 21.25, K 최대 31, 후보 연결 16,320.
  learnable True, L6 적용 (이웃 395~593 = 위치 6~9 × 66 − 1).

11-4. V4 L3 — 같은 채널의 격자 이웃 평균 (2,112 뉴런)
  ★ 연결: V4 L3 (P, c) ← grid_neighbors(4, 8, 반경 1) 의 모든 위치 Q (자기 포함) 의 V4 L2 (Q, c), 각 1/|N(P)|.
     안쪽·바깥 고리 위치는 6 개 (1/6), 가운데 고리는 9 개 (1/9). 연결 15,840 개.
     예) V4 L3 local 0 ← V4 L2 local 0, 66, 462, 528, 594, 990 (각 0.1667).
  각 V4 L2 뉴런은 6~9 개의 L3 에 들어간다 (팬아웃 6~9) → 교정 배분 R 이 일대일이 아닌 유일한 층 (V1 L3 제외).

15-4. ★ build_band_table [L3638] — 후보 연결을 만드는 규칙
  입력: L4 (V4 L4 LayerSpec), l2_rf = V4 L2 의 위치별 수용장 반경 (= 블록 수용장 + D), curve_info, contour 채널 표, D.
  위치 P 마다 (32 개):
     R_j = l2_rf[P]  (처리 영상 화소 거리. 저장된 V4 L2 수용장을 그대로 쓴다 — 후보를 늘리려고 바꾸지 않음)
     qs = { V4 L4 위치 Q : Q ≠ P 이고 ‖Q − P‖ ≤ R_j }       ← 후보 위치 (같은 P 의 곡선 채널 24 개가 같은 위치 집합을 쓴다)
     곡선 채널마다 (θA = oris[i], θB = oris[j], s, κ):
        φC = θA + s·κ/2 (연속 각도),  T_j = P + D(P)·(cos φC, sin φC)  (시각 좌표: x 오른쪽, y 위쪽)
        후보 Q 마다:
           w0 = w_floor + (1 − w_floor)·exp(−‖Q − T_j‖² / (2·D(P)²))        (w_floor 0.05 → w0 ∈ [0.05, 1])
           진단값: d = ‖Q−P‖, d/D, 현 방향 오차 = |방향(P→Q) − φC|, v2 사유 코드 (거리 [0.5D,1.5D] 밖 6, 현 45° 밖 7,
                   아니면 Hermite 경로 검사 결과 1~5 또는 0)
           주소: src = Q × 54 + contour[θB] (V4 L4 의 θB 윤곽 뉴런),  zi = Q × 12 + j (z 벡터 안 번호)
        곡선 행 = P × 66 + 채널,  srcA = P × 54 + contour[θA].
  ★ 후보 조건은 오직 (Q ≠ P, 수용장 안, θB 윤곽 채널, 유효 주소, 중복 없음) 이다. v2 의 거리·현 방향·곡률 검사는 진단값으로만
     저장하고 지우지 않는다. 기본 설정: 뉴런당 후보 10~31 (중앙 22, 평균 21.25), 후보 연결 16,320, 후보 없음 0,
     v2 규칙이었다면 이 후보 중 2.2 % 만 남는다.
  정규화 이웃: contour 뉴런 (위치 p, 방향 o) 마다 grid_neighbors(4, 8, 반경 1) 의 위치 q (자기 포함) 의 같은 방향 o → 6~9 개.
  패딩: 후보 수가 뉴런마다 달라 K = 최대값으로 맞추고, 빈칸 주소는 0 열, 빈칸 w0 = 0, 마스크 False.

15-5. ★ BandRuntime [L3729] — 배치마다 B 를 계산하는 장치 쪽 객체
  생성자: 후보 주소·마스크·w0·log w0, 정규화 이웃, curve_map (V4 L2 행 → 곡선 번호, 곡선이 아니면 nc = 0 패딩 열),
          μ = 0, σ = 1 로 시작 (보정 전에는 band_gated 계산을 거부한다).
  set_calibration(cal): 보정 결과의 모양·표 해시가 이 표와 맞는지, μ·σ 가 유한하고 σ > 0 인지 확인한 뒤 장치로 올린다.
  normalize(xe) [L3771] — z 계산 (원천 뉴런마다 한 번, 여러 곡선 뉴런이 재사용):
     xc = xe[:, contour_src]                         (B, 384) — V4 L4 contour 뉴런의 실제 전송 출력 x
     nbx = 이웃 값 (B, 384, Knb), 빈칸 0
     s = 이웃 최댓값;  rms = s · sqrt( Σ (nbx/s)² / 이웃 수 )   (= sqrt(mean x²) 를 넘침 없이 계산)
     z = xc / (rms + ε),  ε = 1e-6
     표본마다 따로 (배치의 다른 이미지 미사용), 라벨·prototype 미사용. L6 와 별도이며 q 를 바꾸지 않는다. 입력이 모두 0 이면 z = 0.
  combine(xe, mode, record) [L3782] — 곡선 뉴런 행을 조각으로 나눠 계산 (max_gather 기준):
     X = xe[:, cand_src]   (B, r, K)  ← 후보의 원래 x (가중평균 전까지 주소별로 유지)
     Z = z[:, cand_zi]     (B, r, K)  ← 후보의 z (구간 판단에만 사용)
     expanded_pool:  w = w0 (유효 후보), g = 1.
     band_gated:     g = exp(−(Z − μ)² / (2σ²))
                     log w = log w0 − (Z − μ)²/(2σ²);  w = exp(log w − 행별 최댓값)   ← 수치 안정화 (비율은 같다)
                     max g < gate_floor (1e-4) 이고 후보가 있으면 → w = w0 로 되돌리고 all_gates_low = True (기록)
     B = Σ w·X / Σ w   (Σw = 0 이면 0)       share = w / Σw  (실제 기여 몫, 합 1)
     record=True 면 X, Z, G, share, z_contour 를 함께 돌려준다 (기록·조회·그림용).
  성질 (검사 B04·B05·B06 이 확인): 모든 g = 1 이면 expanded_pool 과 같다. 모든 후보 값이 c 면 B = c. w0 에 같은 상수를
     곱해도 B 불변. B 는 유효 후보 x 의 최솟값과 최댓값 사이. 후보가 많아도 출력이 커지지 않는다 (합산이 아니라 평균).
  이 B 는 순방향에서 곡선 행의 정적 B 자리에 들어가 u = min(A, B) 가 된다 (제 16 부 forward).

        (V4 prototype 초기화와 학습 전 평가가 이미 게이트된 출력을 써야 하므로 V4 학습보다 먼저 한다.)
  순서:
    1) 고정 seed 의 별도 RNG default_rng([seed, 4040]) 로 train 항목을 섞어 최대 1024 장을 고른다 (dev/test 미사용).
    2) routing/band_calibration_partial.npz 가 있고 모델 해시·표 해시·표본 목록이 같으면 처리한 표본 수부터 이어서 한다.
       다르면 버리고 처음부터.
    3) 배치마다: LGN → (기존 모델로) V2 L3 까지 순방향 → _static_layer_out [L3938] 으로 V4 L4 출력 계산
       (아직 모델에 없는 층을 forward 와 같은 순서로: A·B 결합 → 임계값 → q = q_init → L6 (L4 는 없음)).

       (메뉴는 "V2 는 아직 동결하지 않았다, 다시 메뉴 5 를 고르면 이어서 한다" 를 알린다).
    5) 연결 (j, 후보 k) 마다: A_j > 1e-6 이고 x_i > 1e-6 인 표본의 z_i 만 모아
         표본 수 ≥ 16:  μ = median(z),  σ = max(1.4826 × median(|z − μ|), 0.5)
         표본 수 < 16:  μ = 1, σ = 2 (calibration_insufficient)
       (연결 행을 조각으로 나눠 nanmedian 으로 계산 — 조각당 30 MB 이하.)
    6) BandCalibration 을 만들고 부분 파일을 지운다. 표본 수·연결 수·표본 부족 연결 수·시간을 출력한다.
  q·prototype 을 바꾸지 않는다. 보정 뒤 μ, σ 는 학습·dev·test·추론에서 고정된다 (이미지·에폭마다 옮기지 않음).
  expanded_pool 실행에서도 같은 보정을 계산해 두지만 그 모드의 순방향에는 쓰지 않는다 (진단 9-6 비교용).

16-1. BucketELL [L4077] — CSR 연결 목록을 GPU 에서 빠르게 계산하는 형태로 바꾼다
  문제: 뉴런마다 팬인이 다르다 (V1 L2 는 84~1,084). 행마다 반복하면 느리고, 가장 큰 팬인으로 모두 채우면 메모리가 크다.
  방법:
    1) 행 j 의 팬인 f_j 를 2 의 거듭제곱 K_j (1, 2, 4, …, 1024, 2048) 로 올린다.
    2) 같은 K 인 행끼리 묶어 (행 수 × K) 크기의 주소 표 idx 와 가중치 표 w 를 만든다. 빈칸 주소는 0 패딩 열 (n_src), 가중치 0.
    3) apply(xe): 묶음마다 Backend.ell (Σ_k xe[:, idx]·w) 로 계산해 이어 붙이고, 고정 역순열 (inv) 로 원래 행 순서에 놓는다.
  각 행은 정확히 한 묶음에만 속하고 atomic 누적이 없어 결과가 결정적이다. slots = 실제 저장 칸 수 (메모리 추정에 사용).

16-2. LayerRuntime [L4123] — 한 층의 장치 쪽 고정 배열
  A = BucketELL(A 입력), Bm = BucketELL(B 입력, 있을 때만), op_min (장치 bool), l6 적용 여부 (설정 l6.layers 에 있고 L2·L3 인 층),
  L6 이웃 수 nb_count = (이웃 위치 수 × 채널 수) − 1 (자기 제외), has_nb, nb_div,
  missing (후보 없는 곡선 행; 있을 때만), routing (v2 RoutingRuntime), band (v3 BandRuntime) — 둘 다 V4/L2 에만 붙는다.

16-3. RelativeActivityController = L6 [L4152]
  같은 층의 L6 조절 전 CONF 를 모두 계산한 뒤, 그 스냅샷에서 한 번에 (병렬로):
    위치 합 pos_sum[p] = Σ_채널 CONF(p, ·)
    이웃 합 = Σ_{q ∈ N(p)} pos_sum[q]  (N(p) = Chebyshev 반경 1 의 위치, 자기 위치 포함) − CONF_j  (자기 자신만 뺌)
    mean = 이웃 합 / 이웃 수      r_j = CONF_j / (mean + ε)
    g_j = clip(1 + κ·(r_j − 1), 0.5, 2.0)        (κ = 0.25)       이웃이 없으면 g = 1
    transmitted_j = g_j · CONF_j
  즉 "같은 층의 공간 이웃 (모든 채널) 평균보다 강하면 키우고, 약하면 줄인다". 방향 선택적 가중치·반복·적응은 없다.
  라벨·prototype 을 쓰지 않고 q 를 바꾸지 않는다 (g 는 이번 입력에만 쓰는 값).
  적용 층: 각 영역 L2·L3 (V1 L2/L3, V2 L2/L3, V4 L2/L3, IT L2/L3). L4 에는 없다.

16-4. CortexModel [L4188]
  보유: NeuronStore, NeuronInspector, specs (층별 LayerSpec), rt (층별 LayerRuntime), areas (만든 영역 순서), active (학습 중인 영역),
        struct_hash (영역별 구조 해시), routers (영역별 LocalErrorRouter), L6 객체, timer.
  plan(area) [L4218]: 다음에 만들 수 있는 영역만 허용 (V1 → V2 → V4 → IT 순서). 앞 영역 L3 를 넘겨 생성기를 부른다.
  add_area(area, specs) [L4225]: 층 순서 검사 → NeuronStore 에 추가 (neuron_id 부여·q 초기화·NEXT 생성) → 층마다 LayerRuntime 생성,

16-5. ★ forward(lgn, upto, keep, override, routing_mode, guide_transform, routing_record) [L4251] — 한 배치의 순방향
  입력 lgn: (B, 4,096) LGN 벡터. 층을 L4 → L2 → L3 → 다음 영역 L4 … 순서로 하나씩 계산한다.
  층마다 (key):
    (1) rt = override 가 있으면 그 층 대체 구조 (진단용), 없으면 정상 구조. 원천이 직전 층이 아니면 오류 (연결 순서 보장).
    (2) xe = [직전 층 실제 전송 출력, 0]        ← 0 패딩 열 (빈 연결 칸 주소)
    (3) sa = A 입력 합 = Σ_{i∈A_j} A_ji · xe_i     (BucketELL)
    (4) B 입력이 있는 층이면 (V2 L2, V4 L2, IT L2):
          sb = Σ_{i∈B_j} A_ji · xe_i   (정적 B; 없으면 0)
          v2 라우팅 층 (V4 L2, geometry_only/v1_guided): 같은 순방향에서 이미 계산한 V1 L3 출력을 안내로 읽어 후보 하나를 고르고,
             그 B 값을 곡선 행 자리에 넣는다 (curve_map 으로 곡선이 아닌 행에는 0).
          v3 구간 층 (V4 L2, expanded_pool/band_gated): band.combine(xe) 로 곡선 뉴런마다 B (가중평균) 를 계산해 곡선 행 자리에 넣는다.
             routing_mode 인자로 이 호출만 expanded_pool / band_gated 를 바꿔 볼 수 있다 (같은 동결 모델의 민감도 검사).
          u = where(op_min, min(sa, sb), sa + sb)   (선형 행은 sb = 0 이라 u = sa)
          후보 없는 곡선 행 (missing) 은 u = 0.
        B 가 없는 층: u = sa.
    (5) s = max(0, u − θ)        (θ = 0)
    (6) CONF = q · s              (q = 그 뉴런의 지속 출력 배율; L4 는 1 로 고정)
    (7) L6 층이면 g = L6.gain(CONF), 실제 전송 출력 out = g · CONF. 아니면 out = CONF.
    (8) keep 에 있는 층은 {u, s, conf, g, out} 을 돌려주고, 모든 L3 는 {out} 을 돌려준다. 라우팅·구간 기록도 붙인다
        (곡선 뉴런의 A = sa[:, 곡선 행], B, all_gates_low, max g, 기록 시 후보별 x·z·g·share).
    (9) out 이 다음 층의 입력이 된다.
  forward 는 표본마다 모든 동적 값을 새로 계산하고 아무것도 남기지 않는다 (지속 상태는 q 와 prototype 뿐).
  감각 회로에 재귀 흥분 연결은 없다 (항상 앞 층 → 뒤 층).

16-6. structure_summary [L4320]: 영역을 만들기 전에 층별 뉴런 수·연결 수·팬인·min2 수·ELL 칸 수와 예상 메모리
  (구조, 배치 활동, gather 조각, prototype, 기록 버퍼, 기존 모델) 를 계산해 화면에 보여 준다 (추정치).

  · cosine_classify [L4405]: pred = argmax_c cos(h, P_c). ‖h‖ ≤ eps 이면 unknown (−1, 오답으로 센다). 무효 prototype 클래스는 후보에서 뺀다.
      동점 수도 센다. 코사인은 확률이 아니다.
  · 초기화 (Session.init_prototypes): 새 영역을 만들면 q 고정 상태로 train 전체를 순방향해 P_c = 클래스 c 의 h 평균.
  · 갱신 (StageTrainer._epoch_end): 에폭 끝에 한 번, P ← (1−ρ)·P + ρ·(이번 q 로 다시 잰 train 클래스 평균), ρ = 0.05.

 제 18 부. 교정 경로 [L4429–L4581]   ★ 층 사이 "거꾸로" 가는 신호 (역전파가 아님)

18-1. LocalErrorRouter [L4432] — 영역 수준 교정 배분기 (영역마다 하나: L2 와 L3 사이)
  입력 δ = prototype_정답 − h (B × n_L3), StageTrainer 가 계산.
    m_L3[:, j] = α3 · δ[:, j]                                   (α3 = 0.5)
    m_L2[:, i] = α2 · Σ_{j : i ∈ P(j)} δ[:, j] / |P(j)|          (α2 = 0.5)
  P(j) = L3 뉴런 j 의 실제 L2 부모 집합. L3 층의 CSR 입력 목록에서 "주소만" 읽는다 (가중치·전치·미분·무작위 피드백 미사용).
  생성자에서 하는 일:
    · (L3 j, L2 i) 부모 쌍을 중복 없이 모은다. |P(j)| = 0 이면 오류 (부모 없는 L3).
    · coef = 1/|P(j)|. L2 쪽에서 보기 좋게 "L2 i 마다 자기를 부모로 가진 L3 들과 coef" 표 (ch_idx, ch_coef) 를 만든다.
    · R 열 합 (각 L3 j 의 coef 합) = 1 확인, 일대일 여부, L3 자식이 없는 L2 수.
  영역별 실제 모양 (기본 설정):
    V1: L3 하나 = L2 4 개 평균 → m_L2 = α2·δ_j/4 (각 L2 는 한 L3 에만 속함).
    V2: 일대일 → m_L2 = α2·δ.
    V4: L3 하나 = 이웃 위치 6~9 개 같은 채널 평균 → 각 L2 는 6~9 개 L3 의 δ 를 1/|P| 씩 받는다.
    IT: 일대일.
  route(δ) → (m2, m3). 위치에 따른 배달이지 유익한 교정이라는 보장이 아니다 (부호·비선형·min2·L6 를 역산하지 않는다).

18-2. L1Packet / L1Relay [L4488–L4536] — 교정 신호의 주소 확인 배달
  패킷 = (영역, 층, neuron_id 범위, 범위 해시, m, 배치 크기, 표본 ID 해시, 모델 버전, kind = teacher_correction).
  deliver(): 영역·층 (L2/L3 만)·범위·해시·모양 (B, n)·유한성을 확인하고, 하나라도 틀리면 L1AddressError 로 거부한다.
  패킷은 배치마다 새로 만들고 남기지 않는다. 오차를 계산하지 않는 논리 구획이다.

18-3. LocalOutputLearner [L4543] — q 갱신 (유일한 학습 규칙)
    e_j  = s_j / (s_j + e0)                 s = 같은 순방향의 L6 조절 전 활동 (max(0, u − θ)), e0 = 1
    Δq_j = η · mean_batch(e_j · m_j)          η = 0.01
    q_j  ← clip(q_j + Δq_j, q_min = 0, q_max = 4)
  proposal(s, m): Δq 계산. apply(): L2·L3 의 Δq 를 같은 스냅샷에서 모두 계산한 뒤 동시에 적용 (NaN/Inf 이면 적용하지 않고 오류).
  통계: 갱신 크기, 범위에 걸린 수, 바뀐 수, q 평균·최소·최대.
  m = 0 이면 Δq = 0 (정확히). s = 0 인 뉴런 (이번 입력에서 꺼짐) 은 e = 0 이라 바뀌지 않는다.
  학습하는 것은 활성 영역의 L2·L3 q 뿐이다. 연결 가중치 A_ji, 임계값, L4 q, 앞 영역 q, v3 의 w0·μ·σ 는 바꾸지 않는다.

      · 배치 항목 = 에폭 순열의 [bi·B, (bi+1)·B). 배치 전 L2·L3 q 를 복사해 둔다 (snap).
      · _batch → (critical 구간에서) _commit. 예외면 q 를 snap 으로 되돌린다.
        GPU 메모리 부족이면 gather 조각 (max_gather) 을 반으로 줄여 같은 배치를 최대 3 번 다시 계산 (배치 크기·수식은 같음,
        oom_events.jsonl 기록). 그래도 실패하면 "oom" 으로 멈추고 안내. 그 밖의 오류는 "failed" checkpoint 후 예외.
      · 배치가 많으면 진행률 출력, 50 배치마다 주기 checkpoint.
    에폭의 모든 배치를 마치면 phase = train_done, checkpoint.
    _epoch_end → 화면에 dev 정확도·개선 비율·q 효과·prototype 효과·상태 출력. 끝난 상태면 반복 종료.
  끝: 상태 확정, 구조 불변·동결 검사 기록, checkpoint "{영역}_stage_{상태}" (keep).

20-4. ★ _batch [L5692] — 배치 하나의 교정 순환 (같은 입력)
  (1) LGN 배치와 라벨. (자체 검사용 결함 주입 oom_once 가 있으면 가짜 메모리 부족.)
  (2) 자유 순방향 f0 = forward(upto=활성 영역, keep=(L2, L3), 라우팅/구간 기록) → h0 = 활성 영역 L3 출력.
  (3) V4 이상이면 구간 (또는 라우팅) 배치 통계와, 상한 (에폭당 8, 단계당 64) 안에서 표본별 후보 x·z·g·share·A·B 기록을 만든다.
  (4) 교정 (timer "correction"):
        vp = 정답 prototype 이 유효한 표본,  T = prototype_정답
        δ = (T − h0) × vp                                    (무효 prototype 표본은 δ = 0)
        m2, m3 = router.route(δ)                             (L3 부모 목록에 따라 L2 로 배분)
        L1Relay 로 L2·L3 패킷 배달 (주소·모양 확인)
        Δq2 = learner.proposal(f0 L2 의 s, m2),  Δq3 = learner.proposal(f0 L3 의 s, m3)
  (5) 갱신 (timer "update", critical): learner.apply({L2: Δq2, L3: Δq3}) — 동시에 적용.
      (결함 주입 interrupt_after_apply 면 여기서 즉시 중단 → 되돌림 검사용.)
  (6) 같은 입력 재순방향 → h1 (실제 네트워크 출력).
  (7) 같은 이전 prototype T 기준 비교: d0 = ‖T − h0‖, d1 = ‖T − h1‖, 코사인 c0·c1, h 변화 방향과 δ 의 코사인,
      크기 오차 (‖T‖ − ‖h0‖), 방향 오차 각도, L2·L3 활동 비율·s 평균·CONF 평균·g 가 하한/상한에 걸린 비율.
  (8) 교정 표본 기록 (에폭당 64, 단계당 512 상한).
  _commit [L5802]: 위 값을 에폭 누적 acc 에 더한다 (개선 d1 < d0 − tol, 악화, 무변화 수 포함), 표본 버퍼에 넣고, 라우팅/구간 통계를
    routing_acc 에 더하고, next_batch += 1. (critical 구간이라 중간에 끊기지 않는다.)

20-5. ★ _epoch_end [L5865] — 에폭 끝 처리
  (1) q 고정, train 전체 재순방향 (현재 prototype 으로 정확도·거리도 잼) → 클래스 평균 h̄.
  (2) P_new = P_old + ρ·(h̄ − P_old)  (표본이 있는 클래스만, ρ = 0.05) → bank.set, prototype 기록.
  (3) 새 prototype 기준 train 거리, dev 평가 (갱신 없음).
  (4) q 효과 = (에폭 끝 거리, 옛 P) − (에폭 시작 거리, 옛 P),  prototype 효과 = (새 P 거리) − (옛 P 거리) → 두 효과를 나눠 기록.
  (5) training.csv 한 줄: 위 통계, L2/L3 별 Δq 크기·범위 걸림·q 평균·최소·최대·q_min/q_max 에 붙은 수·활동·g, 단계별 시간,
      클래스별 dev 정확도·혼동행렬, 캐시 크기, gather 조각 크기, GPU 최대 메모리 (CUDA 일 때), 라우팅/구간 train·dev 요약
      (band_routing_summary.csv 에 train_epoch 과 dev_eval 줄).
  (6) best dev 갱신, 상태 판정: 성공 기준 충족 → success_criterion_met, patience 연속 개선 없음 → plateau,
      예산 소진 → budget_exhausted, 아니면 running. 단계가 끝나도 best 상태로 되돌리지 않는다 (마지막 상태를 그대로 쓴다).
  (7) phase = training, next_batch = 0, 누적 초기화, checkpoint "{영역}_e{에폭}_done", training.csv 동기화.

21-1. run_basic [L6029] — 기본 검사 14 개 (메뉴 7-1). 각 결과를 diagnostics/basic_*.json 과 diagnostics.json 색인에 남긴다.
  C01 반복 순방향 불변: 같은 상태·입력의 두 순방향이 모든 층에서 완전히 같고, 평가 (코사인 분류) 전후 q·prototype 해시가 같다.
  C02 m = 0 이면 Δq = 0, q 가 유한하고 범위 안, 모든 L4 의 q 가 q_init (1.0) 그대로.
  C03 L1 주소: 정상 패킷은 배달되고, 층·영역·id 해시·범위·모양을 바꾼 위조 패킷 5 종은 모두 거부. 실제로 바뀐 q 가
      활성 영역 L2·L3 의 id 범위 안에만 있다.
  C04 배분 R: 영역마다 R 열 합 = 1, 명시적 부모 반복 계산과 route() 결과 일치, 일대일 영역은 m_L2 = α2·δ 가 정확히 같다.
  C05 입력 합 재계산: 층마다 무작위 뉴런 (+ 곡선 행) 의 u 를 CSR 목록으로 직접 다시 계산해 순방향 u 와 비교 (상대오차 < 1e-5).
      곡선 행: v3 는 float64 기준식 B, v2 는 실제로 고른 B 주소로. 후보 없는 행은 u = 0. → 연결 목록과 실제 계산이 같은지 확인.
  C06 동결 영역 불변 (q·prototype·구조·전처리).
  C07 prototype 이 train 출력으로만 만들어졌는지 (모든 갱신의 split = train, 표본 ID 해시 = train, 개수 합 = train 수), 분할 접근 횟수.
  C08 L6 가 q 를 바꾸지 않고, out = g × CONF, g 가 [0.5, 2] 안.
  C09 q 변화가 다음 순방향에 남는가: L3 뉴런 하나의 q 를 0.5 올리면 그 출력이 바뀌고 다음 순방향에서도 같다 (L6 로 바뀐 다른 뉴런 수도 기록).
  C10 반응 없는 뉴런 측정: 탐침 표본에서 s 가 항상 0 인 수, q 가 하한·상한에 붙은 수, g 가 경계에 붙은 수 (MEASURED).
  C11 한 번의 국소 갱신 뒤 h 전·후 거리 (MEASURED, 통과 조건 아님).
  C12 prototype·출력 기하: prototype 코사인 행렬, 최대 비대각 코사인, collapse 경고 (> 0.996), train 일부의 출력 기하.
  C13 역할 반응 빠른 판 (아래 21-2, quick=True).
  C14 전역 기울기 없음: 학습 경로 클래스 소스의 금지 패턴, 텐서 requires_grad, grad mode 꺼짐.

24-3. implementation_checks B01~B12 [L7762] (메뉴 9-4, 구현 검사 = PASSED / FAILED / NOT_RUN)
  B01 후보 규칙 (구조): 곡선 뉴런마다 후보 집합이 "수용장 안 모든 위치 (Q ≠ P) 전수 열거" 와 정확히 같은지, 각 후보가 θB 윤곽 채널·
      유효 주소·수용장 안·z 번호 일치·중복 없음인지, R_j 가 저장된 V4 L2 수용장과 같은지, 0 패딩, 첫 입력 A = (P, θA).
      v2 규칙이었다면 지워졌을 후보도 남아 있는지 (기본 설정에서 대부분). V4 L4·L3·곡선이 아닌 L2 행·곡선 A·뉴런 수·수용장·좌표가
      legacy 구조와 같은지 (후보를 늘리려고 구조를 바꾸지 않았음).
  B02 가장자리 경우: 후보 없음 행·한 후보 행을 만든 사본 표로, 입력 0·1e-30·1e30·무작위·한 값만·실제·실제 일부 ×1e20 에서
      두 모드 모두 NaN/Inf 없음, float64 기준식과 상대오차 2e-5 이내, B ≥ 0, 후보 없음 B = 0, 한 후보 B = 그 x, 입력 0 → z = B = 0.
      모델 전체에 0 입력을 넣으면 모든 층 출력이 0.
  B03 정규화 표본 독립: 배치·표본 하나씩·역순에서 z, B, 출력이 같고, 다른 표본을 크게 바꿔도 첫 표본의 z 가 그대로.
  B04 g = 1 (σ → ∞) 이면 band_gated 결합 = expanded_pool, 모델 경로의 expanded_pool B = 기준식.
  B05 가중평균 성질: 상수 입력 c (0.37, 5000, 1e-7) → B = c, w0 × 7.3 / × 0.001 에도 B 불변, B 가 후보 x 의 최소·최대 사이.
  B06 all_gates_low 대체 경로: 모든 구간을 닫은 인공 보정 (μ = 1e4) 에서 후보 있는 행은 전부 all_gates_low, 후보 없는 행은 아님,
      B = w0 가중평균 (expanded_pool 과 같음), 입력 0 이면 B = 0, 통계의 all_gates_low·후보 없음 수가 따로 맞게 세어짐.
  B07 구간 경계 근처 연속성: 후보 하나의 x 를 0~3×(최대 x) 로 300 칸·600 칸 훑어, 대체 경로 전환이 아닌 칸의 최대 계단이
      0.75 배 이하로 줄면 연속. 실제 보정과, 그 후보만 좁은 구간에 두고 나머지를 닫은 인공 보정 (max g 가 gate_floor 를 지나가게) 두 경우.
      대체 경로 전환에서 생기는 계단은 따로 기록 (설계상 불연속).
  B08 라벨 불변: 게이트·보정 함수 인자에 라벨류 이름 없음, 보정 코드에서 라벨 변수는 받기만 하고 쓰지 않음, 라벨만 바꾼 입력의
      B·G·share·Z·출력이 같음, 보정 표본이 모두 train 이고 dev/test 와 겹치지 않음.
  B09 dev 평가·추론 뒤 지속 상태 불변: q·prototype·구조·표·보정·장치 μ/σ·RNG 해시가 같고, 평가·추론 경로 소스에 상태를 바꾸는 호출
      (set_calibration, run_band_calibration, assign_ 등) 이 없음. test 는 같은 evaluate 경로라 시험 세트를 보지 않으려고 dev 로 검사.
  B10 CPU/GPU 비교: CUDA 에서만 (GPU 결과 대 float64 기준식, 대 NumPy float32, 허용 상대오차 1e-4). 아니면 NOT_RUN.
  B11 저장·재개 재현: checkpoint 의 표 해시 = 현재 = 다시 만든 표, checkpoint μ·σ 로 다시 만든 보정 해시 = 현재 = band_calibration.npz,
      보정 모델 해시 재계산 일치, 다시 만든 런타임의 B 가 현재와 비트 단위로 같음.
  B12 기존 모드 보존: 같은 폴더의 원본 v2 파일과 legacy·geometry_only·v1_guided 의 구조 해시·설정 해시·출력·선택 비교 (최대 차 0 이어야 함),
      원본 v1 파일과 legacy 비교 (R01 재사용). 파일이 없으면 NOT_RUN.
  결과: diagnostics/band_checks_*.json, diagnostics.json 색인. 마지막에 상태 복원 확인.
