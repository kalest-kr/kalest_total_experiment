# BIOLOGY_AND_ASSUMPTIONS.md — 관찰 사실 / 계산 근사 / 미검증 가설 / 생략 범위

이 문서는 **어디까지가 근거 있는 구조 제약이고 어디부터가 모형 파라미터인지**를
구분한다. 이 프로젝트의 결과를 "인간 뇌의 완전하고 정확한 복제" 라고 부르지 않는다.
인간 시각피질의 정확한 개별 연결망(connectome)이 주어지지 않았기 때문이다.

기본 종 기준은 **영장류 시각피질**이다 (orientation/pinwheel 지도와 ocular
dominance 지도를 설명하기에 적합한 기준). 설치류 결과를 차용한 부분은 아래에
종과 외삽 가정을 표시했다.

## 0. 이 작업에서 실제로 확인한 것과 확인하지 못한 것

* 이 저장소를 만드는 동안 **첨부 원문(Rao.pdf, s41597-023-02214-y.pdf)을 받지
  못했다.** 따라서 그 원문을 읽었다고 쓰지 않는다. Rao & Ballard 의 식 형태는
  이 프로젝트의 명세에 적힌 목적함수와 갱신식을 그대로 구현한 것이다.
* 웹 자료(Markov 등의 hierarchy 논문, Diehl & Cook 2015)도 이 작업 중에 직접
  열람하지 않았다. 아래에서 인용하는 것은 **명세가 제시한 범위의 정성적 경향**
  이며, 구체적 수치를 그 논문에서 가져오지 않았다.
* 아래 표의 모든 수치는 별도 표시가 없으면 **모형 파라미터**다.

## 1. 관찰된 사실로 취급한 정성적 제약

| 항목 | 이 구현에서의 취급 | 근거 수준 |
|---|---|---|
| 망막→LGN→V1 의 상향 경로가 존재하고 retinotopy 가 보존된다 | 실제 배선으로 구현 | 널리 보고된 정성적 사실 |
| V1 주 상향 입력이 L4 로 들어간다 | 주 경로로 구현. **다른 층의 감각 입력을 금지하지 않는다** (약한 LGN→L6 경로 포함) | 정성적 경향 |
| 상향 투사는 주로 상부층(L2/3) 기원, 중간층(L4) 표적 / 하향은 L4 밖 표적 | 규칙의 기본값으로 구현하되 **기원/종말층 혼합 경로를 함께 둔다** | 집단 수준 경향 (Markov 등). 개별 시냅스의 완전한 목록이 아니다 |
| L1 은 세포체 밀도가 낮고 첨단수상돌기와 피드백 접점이 모인다 | 소수의 억제 뉴런 + 피라미드 `apical_depth_mm` 를 L1 깊이에 배치 | 정성적 사실 |
| PV 계열은 주로 세포체 주변, SST 계열은 주로 원위/첨단 수상돌기를 표적으로 한다 | `target_compartment` 를 soma / apical 로 나눠 구현 | 정성적 경향. **설치류 연구에서 많이 온 구분이며 영장류 외삽 가정이다** |
| 시각피질에 방향 선호 지도와 pinwheel 특이점이 있다 | 무작위 위상 평면파 중첩 모형으로 생성하고, 뉴런 **위치가 선호 방향을 결정**하게 함 | 영장류/고양이에서 보고된 정성적 사실. 지도의 구체적 형태는 모형 |
| 안구 우세 지도가 방향 지도와 별개 속성으로 존재한다 | 별도 줄무늬 지도로 구현 | 정성적 사실 |
| 중심시야가 피질에서 확대되어 표현된다 | 피질 표면 `u` 축을 `rho` 축에 대응시켜 구현 | 정성적 사실. 확대 계수의 구체값은 모형 |
| 축삭 전도 지연과 시냅스 지연이 존재한다 | 거리/전도속도 + 시냅스 지연으로 구현 | 정성적 사실 |
| Dale 원리 (한 뉴런의 출력 유형이 일정) | 전면 강제 (학습이 부호를 뒤집지 못함) | 널리 쓰이는 제약 |

## 2. 계산 근사 (명시적으로 채택한 선택)

| 근사 | 내용 | 왜 근사인가 |
|---|---|---|
| 구획 수 | soma/basal/apical 3구획 (억제 뉴런은 soma 1구획) | 실제 수상돌기 형태를 재현하지 않는다 |
| 스파이크 생성 | 임계값 교차 + 리셋 (LIF) | Na/K 채널 동역학을 구현하지 않았다 |
| 시냅스 | AMPA / NMDA / GABA_A 의 단일 지수 감쇠 | 상승 시정수, 단기 가소성, GABA_B, 칼슘 동역학 없음 |
| NMDA Mg 차단 | `B(V)` 를 스텝 시작 전압에서 평가 (선형화) | 완전 암시적 해가 아니다 |
| 축삭 길이 | 3D 직선 거리 | 실제 축삭 경로 길이가 아니다 (`use_straight_line_distance` 로 표시) |
| 영역 배치 | 영역을 표면 좌표에서 나란히 배치 | 실제 뇌의 해부학적 위치가 아니다 |
| 피질 사상 | `u↔rho`, `v↔theta` 의 로그-극좌표 사상 | 개별 뇌의 측정 지도가 아니다 |
| 중심 특이점 | 반경 `fovea_patch.radius_deg` 안쪽을 Cartesian 격자로 대체 | 로그-극좌표의 중심 발산을 피하는 공학적 처리 |
| 색 | RGB → XYZ → LMS 선형 근사 | **3채널 RGB 에서 원추세포 스펙트럼 응답을 복원할 수 없다** |
| 대립 채널 | 고정 `OPPONENT_MATRIX` | 실제 신경절 세포의 측정 가중치가 아니다 |
| 조명 변화 | 곱셈 이득 | 실제 조명/반사 분리 모형이 아니다 |
| 단순/복합 세포 | L2 / L3 에 일대일 대응시키지 **않는다**. 위상 불변성은 측정 대상으로 남긴다 | 이 대응 자체가 계산 가정이다 |
| 12방향 × 2위상 | 계산을 위한 이산화 | 피질이 정확히 24개 균일 채널이라는 뜻이 아니다 |

## 3. 모형 파라미터 (출처가 없는 값)

아래 값들은 **전부 설정 파일의 모형 파라미터**다. 측정값으로 제시하지 않는다.

* 영역별 뉴런 수, 층별 뉴런 수, 세포 유형 비율
* 층 두께 (`layer_thickness_mm`). **모든 종과 영역이 정확히 2 mm 라고 가정하지
  않는다.** 설정 가능한 범위로 두었고 합계를 manifest 에 기록한다.
* 연결 확률, `k` 최근접 후보 수, `rf_match_sigma_deg`
* 가중치 분포 (lognormal median/sigma), 가중치 상하한
* 전도속도, 시냅스 지연
* `C_pF`, `gL_nS`, `EL_mV`, `V_th_mV`, `V_reset_mV`, `t_ref_ms`, `g_couple_nS`
* 수용체 시정수와 역전전위
* STDP 의 `A±`, `τ±`, 항상성의 `η_θ`, `window_ms`, 목표 활동률
* 망막 구동 계수 `current_per_hz_pA`, `sum_mode_scale`, `max_rate_hz`
* DoG 의 `σ_center`, `σ_surround`
* pinwheel `hypercolumn_mm`, ocular dominance `column_width_mm`, `strength`

## 4. 색 변환 행렬의 출처와 정규화

| 행렬 | 정규화 | 상태 |
|---|---|---|
| `RGB_TO_XYZ` | 선형 sRGB(D65) → CIE XYZ. 행 합이 D65 백색점 `(0.95047, 1.0, 1.08883)` | IEC 61966-2-1 의 sRGB 원색/백색점에서 유도되는 표준 계수. **이것을 LMS 행렬이라고 부르지 않는다** |
| `XYZ_TO_LMS_HPE_D65` | Hunt–Pointer–Estévez 행렬의 D65 정규화 형태 | 널리 인용되는 값. **1차 출처 원문을 이번 작업에서 직접 대조하지 않았으므로 가정으로 표시한다** |
| `XYZ_TO_LMS_STOCKMAN_SHARPE` | Stockman & Sharpe 계열 원추 기본함수에서 유도 | 같은 이유로 **가정**으로 표시한다 |

실제 수치는 `cortex/retina.py` 에 그대로 적혀 있고 `MATRIX_PROVENANCE` 에 위 설명이
들어 있다. manifest 에도 사용한 행렬 이름과 설명이 저장된다.

## 5. 미검증 가설 (이 코드가 "구현" 한 것이지 "검증" 한 것이 아니다)

1. 로그-극좌표 불균일 샘플링이 균일 샘플링보다 이 과제에 유리하다 — **미검증**.
   `retinotopy.mapping = "uniform_control"` 로 총 샘플 수를 맞춘 대조군을 제공하지만
   결과는 사용자가 실행해야 나온다.
2. L4 ON/OFF 입력의 공간 수렴과 흥분/억제 조합이 방향 선택성을 만든다 — **미검증**.
   `gabor_initialized` 를 쓰면 초기 배선이 이미 Gabor 모양이므로 그 선택성을
   "학습되었다" 고 말할 수 없다.
3. 상위 영역 피드백이 하위 영역 활동을 유의하게 바꾼다 — 구조는 구현했고
   (`check_11` 이 0 이 아닌 문맥 입력의 효과를 측정), **효과의 크기는 미검증**.
4. STDP + 항상성이 이 회로에서 유용한 표현을 만든다 — **미검증**.
   Diehl & Cook (2015) 의 조합이 좋은 성능을 냈다는 보고가 있어도, 그 성능이
   **이 모형에서 보장되지 않는다**.
5. V2 가 "더 복잡한 형태" 를, V4 가 "색+형태" 를, IT 가 "물체" 를 표현한다 —
   **연구용 작업 가설**이다. 같은 영역이 여러 시각 특성에 관여할 수 있다.
6. 색채 항상성 — **구현했다고 말하지 않는다.** 조명 변화 조건에서의 검증이 있어야
   한다. 현재는 조명 이득을 바꾼 자극을 만들 수 있을 뿐이다.
7. Rao 오차를 apical 전류로 연결하는 경로 — 기본값 꺼짐. 켜는 경우
   단위 변환·양/음 부호화·좌표 대응·연결 학습 여부를 모두 별도 문서화해야 하며,
   **임의 전류 주입이 Rao 식을 재현한다고 가정하지 않는다.**

## 6. 생략 범위 (구현하지 않은 것)

* Na/K 등 능동 이온 채널, Ih, 칼슘 동역학, 수상돌기 스파이크, 버스트 발화
* GABA_B, 대사성 수용체, 신경조절물질
* 단기 가소성(facilitation/depression), 시냅스 방출 확률
* 교세포, 혈류, 대사
* LGN 의 magno/parvo/konio 구분, V1 L4 의 4Cα/4Cβ 등 아형 구분 — **근사로 명시**
* VIP 계열 억제 뉴런 (선택 구현 대상이었으나 이번 범위에서 제외)
* 안구 운동, 조절, 양안 융합 회로
* 운동 방향 선택성 회로 — 프레임 시퀀스 자극은 만들 수 있으나 전용 시간 회로를
  넣지 않았다. **정지영상만 사용한 실행의 운동 지표는 `not_applicable` 이다.**

## 7. 참고 자료의 사용 범위

* **Rao & Ballard (1999), Predictive coding in the visual cortex** — 이 프로젝트는
  명세에 적힌 목적함수/갱신식(식 7~9 계열)을 그대로 구현했다. 이것은 국소 예측
  오차와 학습의 **수학적 기준**이며, 생물학적 L1 전체 회로의 실증 자료가 아니다.
  첨부 PDF 를 이번 작업에서 받지 못해 원문을 읽었다고 쓰지 않는다.
* **Markov 등, Anatomy of hierarchy**
  (https://pmc.ncbi.nlm.nih.gov/articles/PMC4255240/) — 영장류 영역 간 배선의
  기원/종말층 **경향**을 참고했다. 이 논문은 개별 뉴런의 정확한 connectome 을
  제공하지 않으므로, 기원/종말층을 독점적인 한 쌍으로 고정하지 않고 혼합을
  허용했다. 이 작업 중 원문을 직접 열람하지 않았다.
* **Diehl & Cook (2015)**
  (https://www.frontiersin.org/journals/computational-neuroscience/articles/10.3389/fncom.2015.00099/full)
  — STDP + 측면 억제 + 적응 임계값 조합의 계산 모델. **그 조합의 성능이 본 모형에서
  보장된다고 해석하지 않는다.** 이 작업 중 원문을 직접 열람하지 않았다.
* **Gillon 등 (2023), s41597-023-02214-y** — 세포체와 첨단수상돌기의 칼슘 반응
  데이터. 첨부 PDF 를 받지 못해 사용하지 않았다. 사용하게 되더라도 **형광 신호를
  막전위나 시냅스 의미의 직접 정답으로 쓰지 않는다.**

## 8. 결과를 읽을 때의 주의

* 영역 이름만 붙은 일반 MLP 가 아니다. 공간 좌표, 세포 유형, 표적 층·구획,
  흥분/억제, 재귀 연결, 전달 지연이 **실제 계산을 바꾼다**. 그러나 그것이
  생물학적 정확성을 뜻하지는 않는다.
* 100만 화소 입력을 처리한다는 것은 입력 전처리의 규모이지 100만 뉴런 학습이 아니다.
* 단안 영상을 좌/우에 복제해 넣은 입력은 **양안 시차 실험이 아니다**.
* 고정 Gabor 경로와 학습형 경로의 결과를 섞어 "학습된 특징" 으로 보고하지 않는다.
* Rao 참조 모델은 전도도 LIF 회로와 다른 엔진이다. 동일 아키텍처 대조군인 것처럼
  섞어 순위를 매기지 않는다.
