======================================================================================================
 뉴런은 다음 뉴런과 어떻게 연결되는가, 그리고 무엇을 기준으로 그렇게 정하는가
 대상: cortex_local_learning_v3_band_gated_routing.py (v3.0.0, 기본 설정 128×128 화소)
======================================================================================================

[이 문서의 범위]
  1) 정적 연결: 프로그램이 모델을 만들 때 "어느 뉴런이 다음 층의 어느 뉴런으로 이어지는지" 를 정하는 규칙과 그 판정 기준.
  2) 동적 결정: 연결은 고정이지만, 이미지마다 "신호를 실제로 내보낼지, 두 입력 중 어느 쪽이 결과를 정할지, 후보 중 어느 연결을
     더 크게 반영할지 (V4 곡선 뉴런)" 가 계산으로 정해진다. 그 판정 기준.
  3) 거꾸로 가는 교정 신호가 어느 뉴런에 가는지, 그리고 최종 분류 결정 기준.
  모든 예시 숫자는 작성 환경에서 기본 설정의 구조를 실제로 만들어 읽은 값이다 ([L1234] 는 소스 줄 번호).
  동적 예시 (제 6 부) 는 학습하지 않은 모델에 합성 원호 그림 한 장을 넣은 결과이며 성능 수치가 아니다.


======================================================================================================
 제 1 부. 연결을 정하는 큰 원칙
======================================================================================================

1-1. 언제 정해지나
  모든 정적 연결 (누가 누구에게, 가중치 몇) 은 영역을 만들 때 생성 함수 (build_v1 / build_v2 / build_v4 / build_it) 가 한 번 정한다.
  학습 중에는 연결 주소도 가중치도 바뀌지 않는다. 학습으로 바뀌는 것은 뉴런마다의 출력 배율 q 하나뿐이다.
  재개할 때는 같은 규칙으로 구조를 다시 만들어 해시가 저장된 값과 같은지 확인한다 (같은 기준 → 같은 연결).

1-2. 연결의 방향
  · 모든 층은 "바로 앞 층 하나" 에서만 입력을 받는다:
      LGN → V1 L4 → V1 L2 → V1 L3 → V2 L4 → V2 L2 → V2 L3 → V4 L4 → V4 L2 → V4 L3 → IT L4 → IT L2 → IT L3
  · 층을 건너뛰는 연결, 같은 층 안에서 값을 더하는 연결, 뒤에서 앞으로 가는 흥분 연결은 없다.
  · 예외처럼 보이는 것 두 가지:
      - L6 배율: 같은 층 이웃의 활동을 "비교" 해 출력 배율 g 를 곱한다 (값을 보내는 연결이 아님).
      - v2 라우팅 모드 (geometry_only, v1_guided) 에서만 V1 L3 출력이 V4 L2 곡선 뉴런의 후보 "선택" 에 읽힌다 (값을 더하지 않음).
        기본 모드 band_gated 에서는 읽지 않는다.

1-3. 수신 뉴런 쪽에서 본 연결 = "입력군 A, B"
  뉴런 j 의 입력 합 u_j:
      선형 뉴런:  u_j = Σ_{i ∈ A_j} w_ji · x_i
      min2 뉴런:  u_j = min( Σ_{i ∈ A_j} w_ji x_i ,  Σ_{i ∈ B_j} w_ji x_i )     (두 입력군이 모두 있어야 반응)
  x_i = 앞 층 뉴런 i 의 실제 전송 출력. 연결 목록 A_j, B_j 와 가중치 w_ji 가 이 문서에서 설명하는 "연결".

1-4. 연결 판정에 쓰이는 기준의 종류 (아래에서 이 이름으로 부른다)
  (가) 대응 번호      : 같은 번호끼리 하나씩 (일대일).
  (나) 블록 소속      : 아래 격자의 2×2 칸 묶음이 위 격자의 한 칸에 속하면 연결.
  (다) 거리 반경      : 원영상 화소 거리가 반경 이하이면 연결 (V1 수용장, V4 곡선 후보).
  (라) 변위 최근접    : 위치 P 에서 선 방향 θ 로 D 화소 간 점에 가장 가까운 격자 위치 (V2 윤곽·끝점, V4 직선, legacy 곡선).
  (마) 격자 이웃      : 피질 격자에서 Chebyshev 거리 ≤ 1 (각도 wrap, 반경 clip) (V4 L3, L6 이웃, v3 정규화 이웃).
  (바) 채널 조건      : 같은 방향 / 같은 색 / 같은 역할 계열 / 지정한 방향 쌍 (모든 단계에서 위의 공간 기준과 함께).
  (사) 이미지별 계산  : V4 곡선 뉴런의 두 번째 입력 B 는 고정 후보 중 어느 연결을 얼마나 반영할지 이미지마다 계산한다.


======================================================================================================
 제 2 부. 기준에 쓰이는 공통 기하 (위치·좌표·거리)
======================================================================================================

2-1. 뉴런 번호
  한 층의 뉴런 local 번호 = 위치 × (위치당 채널 수) + 채널.  모델 전체 번호 neuron_id = 층 시작 번호 + local.
  층별 neuron_id 범위 (기본 설정):
     V1 L4 0–4,095 · V1 L2 4,096–28,671 · V1 L3 28,672–34,815 · V2 L4 34,816–36,351 · V2 L2 36,352–43,263 ·
     V2 L3 43,264–50,175 · V4 L4 50,176–51,903 · V4 L2 51,904–54,015 · V4 L3 54,016–56,127 · IT L4 56,128–56,655 ·
     IT L2 56,656–56,801 · IT L3 56,802–56,947

2-2. 위치 격자 (로그-극좌표) [logpolar_positions, L1503]
  반경 bin k, 각도 bin m 의 위치: r = r0·(exp(u·L) − 1), u = (k+0.5)/n_r, L = log(1 + Rmax/r0), φ = 2π(m+0.5)/n_phi
  화소 좌표 x = 63.5 + r·cosφ, y = 63.5 − r·sinφ (화면 y 는 아래로 커진다). 위치 번호 = k·n_phi + m.
  격자 크기: LGN 32×64, V1 16×32, V2 8×16, V4 4×8, IT 영역 2×4.
  가운데는 촘촘하고 바깥은 성기다 (예: V4 고리 반경 1.15, 5.42, 15.58, 39.75 화소).

2-3. 블록 [_block_children L2067, _pool_positions L2076]
  위 격자 칸 (K, M) 의 자식 = 아래 격자의 반경 2K, 2K+1 × 각도 2M, 2M+1 (기본 설정은 모든 단계가 2×2).
  위 칸의 중심 = 자식 중심 평균, 수용장 반경 = max(자식까지 거리 + 자식 수용장 반경).
  설정 검사가 아래 격자가 위 격자의 정수배인지 확인하므로 모든 자식은 정확히 한 블록에 속한다.

2-4. 국소 간격과 변위 거리 D [_local_spacing L2084]
  D(P) = max(1.0 × sqrt( ((r + r0)·L/n_r) × (2πr/n_phi) ), 1 화소)   (r = 그 위치의 중심 반경, 그 격자의 n_r, n_phi)
  예) V2 위치 53 (고리 3): D = 3.328 화소, V2 위치 0 (고리 0): 계산값 0.459 → 하한 1 화소, V2 위치 115 (고리 7): D = 20.866 화소.
      V4 고리별 D = 1.568, 5.231, 13.654, 33.606 화소.

2-5. 변위 최근접 위치 [_displaced L2090] — 기준 (라)
  목표점 = (x_P + sign·D·cosθ,  y_P − sign·D·sinθ)   (sign = +1 앞, −1 뒤)
  선택 = 그 격자의 모든 위치 중 목표점까지 유클리드 화소 거리가 가장 작은 위치 (같은 거리면 번호가 작은 쪽).
  그 위치가 P 자신이면 "이웃 없음" 으로 보고 그 연결을 두지 않는다 (개수 기록).

2-6. 격자 이웃 [grid_neighbors L1998] — 기준 (마)
  같은 격자에서 |반경 bin 차| ≤ 1 이고 각도 bin 차 (한 바퀴 wrap) ≤ 1 인 위치 (자기 포함).
  안쪽·바깥 고리는 6 개, 그 사이는 9 개.  예) V2 위치 0 → [0, 1, 15, 16, 17, 31],  V2 위치 53 → [36, 37, 38, 52, 53, 54, 68, 69, 70].


======================================================================================================
 제 3 부. LGN → V1   [build_v1 L2130]
======================================================================================================

3-1. 망막/LGN → V1 L4  (기준: (가) 대응 번호)
  LGN 벡터의 값 i = 위치 × 2 + 맵 (맵 0 = lum_on, 1 = lum_off). V1 L4 뉴런 i 는 그 값 i 하나만 가중치 1 로 받는다.
  예) V1 L4 local 0 = LGN 위치 0 (고리 0, x 63.61, y 63.49) 의 ON,  local 2,001 = LGN 위치 1,000 (고리 15, r 8.72) 의 OFF.
  판정할 것이 없다 (번호가 같으면 연결).

3-2. V1 L4 → V1 L2  (기준: (다) 거리 반경 + (바) 같은 색의 ON·OFF 맵)
  ★ 연결 규칙: V1 L2 위치 p 의 뉴런 (48 채널 모두) 은
       원영상 거리 ‖LGN 표본 위치 − V1 위치 p‖ ≤ rad(p) 인 모든 LGN 표본 위치의 ON 뉴런과 OFF 뉴런에 연결된다.
     rad(p) = 2·σ(p),  σ(p) = max(1.0 × V1 국소 간격, 1.5 화소).   반경 안에 하나도 없으면 가장 가까운 표본 하나 (기본 설정 0 회).
  ★ 가중치 결정 (채널 = 방향 θ, 위상 φ, 극성 ±):
       표본의 상대 좌표 (vx, vy) → along = vx cosθ + vy sinθ,  perp = −vx sinθ + vy cosθ
       env = (표본 면적) · exp(−(along² + perp²)/(2σ²)),  carrier = cos(2π·perp/λ + φ),  λ = 2σ
       g = env · (carrier − env 가중 평균 carrier)  → Σ|g| = 1 로 정규화.
       극성 +: ON 표본 가중치 +g, OFF 표본 가중치 −g.   극성 −: ON −g, OFF +g.
     따라서 연결 "여부" 는 거리만으로, 연결 "세기·부호" 는 그 표본이 Gabor 모양의 어디에 놓였는지로 정해진다.
     carrier 가 perp (선에 수직인 축) 로만 변하므로 θ 방향으로 놓인 선에 가장 크게 반응한다 (채널 θ = 선의 접선 방향).
  예) V1 위치 261 (고리 8, x 68.50, y 54.14): 국소 간격 2.385 → σ = 2.385, λ = 4.770, rad = 4.770 화소.
      반경 안 LGN 표본 54 개 (가장 먼 것 4.619 ≤ 4.770, 반경 밖 가장 가까운 것 4.851) → 팬인 108 (= 54 × ON/OFF).
      채널 "lum_o60_p0_+" 의 가중치: ON 쪽 |합| = 1.0, ON 쪽 합 ≈ 0 (균일 밝기에는 반응 0), 최대 +0.057, 최소 −0.057.
      V1 위치 0 (가운데): σ 하한 1.5 → rad 3.0, 표본 542 개 → 팬인 1,084.  V1 위치 500 (바깥): σ 11.636, rad 23.272, 표본 42 개 → 팬인 84.
  ★ 송신 쪽 (V1 L4 뉴런 하나가 어디로 가는가):
      그 LGN 표본을 반경 안에 둔 모든 V1 위치 × 48 채널. 판정 기준은 같은 거리 비교다 (V1 위치마다 자기 반경으로).
      예) LGN 위치 1,000 (r 8.72) 의 ON 뉴런 → V1 위치 15 곳 × 48 = 720 개의 V1 L2 뉴런.
          LGN 위치 0 (한가운데) → 128 곳 × 48 = 6,144 개.  LGN 가장 바깥 위치 2,047 → 6 곳 × 48 = 288 개.
      (프로그램이 만든 나가는 연결 목록과 "거리 ≤ 반경" 을 다시 계산한 위치 집합이 정확히 같음을 확인했다.)

3-3. V1 L2 → V1 L3  (기준: (가) 같은 위치 + (바) 같은 색·같은 방향)
  ★ V1 L3 (위치 p, 방향 θ) ← 같은 위치·같은 방향의 V1 L2 4 개 (위상 2 × 극성 2), 각 가중치 1/4.
     주소 = p×48 + (방향 번호×2)×2 + {0, 1, 2, 3}.
  예) V1 L3 local 3,136 (위치 261, 60°) ← V1 L2 local 12,544–12,547 = lum_o60_p0_+, p0_−, p1_+, p1_− (각 0.25).
  송신 쪽: 모든 V1 L2 뉴런은 정확히 한 V1 L3 뉴런으로 간다 (팬아웃 1).


======================================================================================================
 제 4 부. V1 → V2   [build_v2 L2257]
======================================================================================================

4-1. V1 L3 → V2 L4  (기준: (나) 블록 소속 + (바) 같은 방향)
  ★ V2 L4 (V2 위치 P, 방향 θ) ← P 블록에 속한 V1 위치 4 곳의 같은 방향 V1 L3, 각 1/4 (색이 여럿이면 색까지 평균).
  예) V2 L4 local 0 (V2 위치 0 = 고리 0 각도 0, 0°) ← V1 L3 local 0, 12, 384, 396 = V1 (고리,각도) (0,0), (0,1), (1,0), (1,1).
      V2 L4 local 642 (V2 위치 53 = 고리 3 각도 5, 90°) ← V1 (6,10), (6,11), (7,10), (7,11) 의 90° 뉴런.
  송신 쪽: 모든 V1 L3 뉴런은 자기 위치가 속한 블록의 V2 L4 한 개로 간다 (팬아웃 1).

4-2. V2 L4 → V2 L2 — 채널 54 개, 세 종류 규칙
  (1) 윤곽 연속 contour_θ  (기준: (라) 변위 최근접 + (바) 같은 방향)
      ★ A = 0.5·o(P, θ) + 0.25·o(앞 이웃, θ) + 0.25·o(뒤 이웃, θ)
         앞·뒤 이웃 = _displaced(P, θ, D, ±1). 이웃이 없으면 (자기 자신이 가장 가까우면) 그 항을 빼고 남은 가중치를 합 1 로 다시 나눈다.
      예) V2 위치 53 (고리 3, x 59.54, y 57.57), D = 3.328, θ = 0°:
            앞 목표점 (62.87, 57.57) → 가장 가까운 위치 52 (거리 1.307, 다음 후보 2.084)
            뒤 목표점 (56.21, 57.57) → 위치 54 (거리 2.392, 다음 2.859)
            → contour_o0 (위치 53) ← V2 L4 (위치 52, 0°) 0.25, (53, 0°) 0.5, (54, 0°) 0.25
          같은 위치에서 θ = 45° 여도 가장 가까운 격자 위치가 다시 52·54 라서 같은 위치 쌍을 쓴다
          (격자가 성기면 서로 다른 방향이 같은 이웃을 고를 수 있다 — 기준은 "가장 가까운 칸" 이기 때문).
      예) V2 위치 115 (바깥 고리 7), θ = 45°: 앞 목표점 (87.93, 0.10) 에 가장 가까운 칸이 자기 자신 (115) → 앞 이웃 없음.
            → contour_o45 ← (100, 45°) 0.333, (115, 45°) 0.667 로 재정규화.  기본 설정에서 앞·뒤 이웃이 없는 윤곽 뉴런 각 48 개.
  (2) 끝점 endstop_θ_fwd / bwd  (기준: (라) + (바))
      ★ A = +1·o(P, θ) − 1·o(P 의 앞 (fwd) 또는 뒤 (bwd) 이웃, θ)
         "그쪽으로 같은 방향 선이 이어지면 억제" → 선이 끝나는 곳에서만 남는다. 이웃이 없으면 억제 항 없이 +1·o(P, θ) 만.
      예) 위치 53, 0°: endstop_o0_fwd ← (53) +1, (52) −1;  endstop_o0_bwd ← (53) +1, (54) −1.
  (3) 교차 cross_θ1_θ2  (기준: (가) 같은 위치 + (바) 지정한 방향 쌍, min2)
      ★ A = o(P, θ1), B = o(P, θ2), u = min(A, B).
         방향 쌍: 방향 차 90° (6 쌍) 와 60° (12 쌍) 의 모든 조합 → 18 채널.
      예) 위치 53 의 cross_o0_o90 ← A = V2 L4 local 636 (53, 0°), B = local 642 (53, 90°).
  ★ 송신 쪽 예) V2 L4 local 636 (위치 53, 0°) 이 가는 곳 (10 개):
      위치 53 의 contour_o0 (0.5), endstop_o0_fwd (+1), endstop_o0_bwd (+1), cross_o0_o90 · cross_o0_o60 · cross_o0_o120 (A),
      위치 52 의 contour_o0 (0.25)·endstop_o0_bwd (−1) (위치 52 의 뒤 이웃이 53 이므로),
      위치 70 의 contour_o0 (0.25)·endstop_o0_fwd (−1) (위치 70 의 앞 이웃이 53 이므로).
      즉 "다른 위치가 자기를 앞·뒤 이웃으로 골랐는가" 에 따라 팬아웃이 6~16 개로 달라진다.
      이웃 관계는 대칭이 아닐 수 있다: 위치 53 의 뒤 이웃은 54 지만, 위치 54 는 53 을 이웃으로 고르지 않았다
      (각자 자기 목표점에 가장 가까운 칸을 고르기 때문).

4-3. V2 L2 → V2 L3  (기준: (가) 대응 번호) — V2 L3 j ← V2 L2 j, 가중치 1. 팬아웃 1.

 제 5 부. V2 → V4 → IT   [build_v4 L2356, build_it L2517]

5-1. V2 L3 → V4 L4  (기준: (나) 블록 소속 + (바) 같은 채널)

  (2) 접합 중계 junction_k  (기준: (가) 같은 위치 + 같은 교차 채널) — A = V4 L4 (P, 교차 채널 k), 가중치 1.

      첫 입력 A (모든 모드 공통): 윤곽(P, θA), 가중치 1.     예) 위치 9 의 curve_o0_to_o30 → A = V4 L4 local 486 (위치 9, contour_o0).

  ★ 송신 쪽 예) V4 L4 local 486 (위치 9, contour_o0) 의 정적 연결 4 개:
      위치 9 의 curve_o0_to_o30 (A), curve_o0_to_o150 (A), straight_o0 (A), 그리고 위치 10 의 straight_o0 (B, 위치 10 의 앞 이웃이 9).

5-3. ★ 곡선 뉴런의 두 번째 입력 B — 모드별 결정 기준
  ┌ legacy (v1 재현)
  │   B = 윤곽(Q, θB),  Q = _displaced(P, θA, D, +1) (기준 (라)). 앞 이웃이 없으면 같은 위치 P. 정적 연결 1 개.
  │
  ├ geometry_only / v1_guided (v2 재현)   [build_routing_table L3205, RoutingRuntime L3312]
  │   정적 후보 (최대 8 개): Q ≠ P, 0.5·D ≤ ‖Q − P‖ ≤ 1.5·D, 이동 방향과 기대 현 방향 φC = θA + s·κ/2 의 차 ≤ 45°,
  │      그리고 P → Q 삼차 Hermite 경로 검사 통과 (진행 방향, 영 접선, 곡률 부호가 s 와 같음, 접힘 없음, 수용장 안).
  │      순서 = 기하 점수 |d − D|/(반폭·D) + 방향오차/45 (같으면 주소 순).
  │   이미지마다 선택: geometry_only = 첫 후보, v1_guided = 경로 위 V1 L3 방향 지지 점수 S 가 가장 큰 후보 (같으면 기하 순서,
  │      모두 0 이하면 첫 후보). B = 고른 후보 하나의 값 (hard top-1). 후보가 없으면 u = 0.
  │   ※ 기본 설정에서 이 규칙은 곡선 뉴런 768 개 중 608 개를 "후보 없음" 으로 만든다 (곡률 부호 검사가 엄격함).
  │
  └ expanded_pool / band_gated (v3, 기본 band_gated)   [build_band_table L3638, BandRuntime L3729]
      ★ 정적 후보 (모두 보존): V4 L4 위치 Q 가
           ① Q ≠ P,  ② 원영상 거리 ‖Q − P‖ ≤ R_j (R_j = 저장된 V4 L2 수용장 반경 = 블록 수용장 + D),
           ③ θB 방향 윤곽 채널, ④ 유효 주소·중복 없음
         이면 후보. v2 의 거리·현 방향·곡률 검사는 "왜 v2 였다면 빠졌을지" 기록만 하고 빼지 않는다.
         한 위치 P 의 곡선 채널 24 개는 같은 후보 위치 집합을 쓰고 채널 (θB) 만 다르다.
      ★ 기하 가중치 (고정): w0 = 0.05 + 0.95·exp(−‖Q − T_j‖²/(2D²)),  T_j = P + D·(cos φC, sin φC)   ("곡선이 다음에 있을 곳" 에 가까울수록 큼)
      ★ 이미지마다 연결 반영 비율: 5-4 와 제 6 부.
      예) 위치 9 (고리 1) 의 curve_o0_to_o30 (θA 0°, θB 30°, s +1, φC 15°): D 5.231, R 13.802, T (70.63, 57.14).
            수용장 안 다른 위치 18 곳이 모두 후보 (반경 밖 가장 가까운 위치는 16.50 화소).

                     Q=16 거리 12.36 (= 2.36·D) → w0 0.411 (v2 였다면 거리 사유로 빠짐)
                     가장 작은 w0: Q=18 (거리 12.36) 0.063.
            이 뉴런의 후보 18 개는 v2 규칙으로는 하나도 남지 않는다 (거리 6, 현 방향 12) → v2 에서는 이 뉴런이 꺼졌다.
          위치 0 (고리 0) 의 같은 채널: R 5.388 → 후보 10 개 (반경 밖 가장 가까운 위치 5.54 화소).
          위치 25 (고리 3) 의 curve_o0_to_o150: R 87.03 → 다른 31 위치 전부 후보. 가장 큰 w0 = Q=24 (0.888).
          후보 수는 고리마다 같다: 고리 0 → 10, 고리 1 → 18, 고리 2 → 26, 고리 3 → 31. 기본 설정에서 후보 없는 곡선 뉴런 0 개.

5-4. v3 곡선 B 의 이미지별 계산 (기준 (사)) [BandRuntime.normalize L3771, combine L3782]
  ① 정규화 강도 z (후보 입력 뉴런마다 한 번):
       z_i = x_i / (10⁻⁶ + sqrt( mean_{k∈N(i)} x_k² )),  N(i) = 같은 방향 윤곽 채널의 V4 격자 이웃 (기준 (마), 자기 포함, 6~9 개)
       → "주변 같은 방향 윤곽보다 상대적으로 얼마나 강한가". 표본마다 따로, 라벨 미사용. z 는 판단에만 쓰고 전달 값은 원래 x.
  ② 구간 일치도 g (연결 j←i 마다):  g = exp(−(z_i − μ_ji)² / (2 σ_ji²))
       μ, σ: V4 를 추가할 때 train 이미지 (최대 1024 장, 라벨 미사용) 로 1 번 정한 값.
       그 연결에서 A_j > 10⁻⁶ 이고 x_i > 10⁻⁶ 이었던 표본의 z 로 μ = 중앙값, σ = max(1.4826·MAD, 0.5).
       그런 표본이 16 개 미만이면 μ = 1, σ = 2 (넓은 기본 구간, 표본 부족 표시). 이후 고정.
  ③ 반영 가중치 w_eff = w0 · g,   B = Σ w_eff·x / Σ w_eff  (가중평균 → 후보 수가 많아도 B 가 커지지 않음)
  ④ 판정 예외:
       · max g < 10⁻⁴ (모든 구간이 맞지 않음) → g 를 무시하고 w0 가중평균 + all_gates_low 기록.
       · 후보가 정말 없는 뉴런 (missing_candidate) → B = 0, u = 0 (같은 위치로 대체하지 않음).
       · expanded_pool 모드 → g = 1 (w0 가중평균).
  ⑤ u = min(A, B) (곡선 뉴런은 min2).

7-1. V4 L2 → V4 L3  (기준: (마) 격자 이웃 + (바) 같은 채널)
  ★ V4 L3 (P, c) ← 격자 이웃 Q ∈ N(P) (자기 포함) 의 V4 L2 (Q, c), 각 1/|N(P)|.

7-2. V4 L3 → IT L4  (기준: (나) 블록 소속 + 같은 채널)

  ★ global_c (66 개)        : A = 8 영역의 채널 c, 각 1/8.          (위치와 무관한 "그 특징이 어디든 있나")
  ★ region_R_군 g (32 개)    : A = 영역 R 의 군 g 채널 전부, 각 1/|g|. (예: region0_curve ← 영역 0 곡선 24 채널, 각 1/24)

======================================================================================================
 제 8 부. 거꾸로 가는 교정 신호는 어느 뉴런으로 가는가 (학습 경로)
======================================================================================================
  감각 연결과 별도로, 학습 중인 영역 (활성 영역) 의 L3 → L2 방향으로만 교정 신호 m 이 간다. 값을 더하는 연결이 아니라 q 학습기로
  가는 배달이다.

8-1. 배달 주소의 결정 기준 [LocalErrorRouter L4432]
  δ = prototype_정답 − h  (활성 영역 L3 뉴런마다)
  ★ L3 뉴런 j 의 신호는 j 의 "정적 입력 목록에 있는 L2 뉴런 (부모 P(j))" 에게만, 1/|P(j)| 씩 간다:
       m_L3[j] = 0.5·δ[j],    m_L2[i] = 0.5·Σ_{j: i ∈ P(j)} δ[j] / |P(j)|
     기준은 주소뿐이다 (연결 가중치·미분·전치를 쓰지 않음).
  영역별 결과: V1 = L3 하나당 부모 4 개 (각 1/4) · V2 = 일대일 · V4 = 부모 6~9 개
     (예: V4 L2 local 594 (위치 9, 곡선) 는 V4 L3 9 곳에서 1/6 또는 1/9 씩 받는다) · IT = 일대일.
8-2. 실제로 q 가 바뀌는 뉴런의 기준 [LocalOutputLearner L4543]
  Δq_j = 0.01 · mean_batch( s_j/(s_j + 1) · m_j ),  q_j ← clip(q_j + Δq_j, 0, 4)
  · 활성 영역의 L2·L3 뉴런만 (L4, 앞 영역, 연결 가중치는 바뀌지 않는다).
  · 이번 배치에서 s_j = 0 (출력이 꺼진) 뉴런은 e = 0 이라 바뀌지 않는다.
  · 정답 클래스 prototype 이 무효 (영벡터) 인 표본은 δ = 0 → 기여 없음.
  · 배달 전에 L1Relay 가 영역·층 (L2/L3)·neuron_id 범위·해시·모양·유한성을 확인하고, 하나라도 틀리면 거부한다.


======================================================================================================
 제 9 부. 최종 결정과 단계 결정의 기준
======================================================================================================
  · 분류 [cosine_classify L4405]: pred = argmax_c cos(h, prototype_c). ‖h‖ ≤ 10⁻¹² 이면 unknown (오답으로 셈),
    무효 prototype 클래스는 후보에서 제외, 같은 값이면 앞 클래스 (동점 수 기록). 코사인은 확률이 아니다.
  · prototype: 영역을 만들 때 train 클래스 평균, 에폭 끝마다 P ← 0.95·P + 0.05·(train 클래스 평균). dev/test·추론에서는 바뀌지 않는다.
  · 학습 단계 종료: dev 정확도 ≥ 성공 기준이면 success, patience (5) 에폭 연속 개선 없으면 plateau, 에폭 예산 소진이면 budget_exhausted.
  · 다음 영역 추가: 사용자가 확인할 때만. 추가하면 현재 영역 q·prototype 을 동결 (해시 감시). 성공 기준 미충족이면 경고를 기록.
  · 구간 보정 표본: 고정 seed RNG ([seed, 4040]) 로 train 에서 최대 1024 장. 중단되면 처리한 표본까지 저장하고 다음에 이어서 한다.
